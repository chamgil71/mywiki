## 10.2 OpenRouter — 500개 AI 모델을 단일 API로

### 1) OpenRouter란?

OpenRouter는 LLM을 위한 통합 인터페이스입니다. 단일 API 키로 OpenAI, Anthropic, Google, DeepSeek 등 주요 AI 제공업체의 모든 모델에 접근할 수 있습니다.

OpenRouter는 LLM API 게이트웨이이자 마켓플레이스입니다. 앱을 다시 구성하지 않고도 멀티 모델 실험이 가능하며, 공급자별 라우팅과 폴백 기능, 통합 로그 및 결제를 제공합니다. OpenAI SDK와 호환되어 기존 앱에서의 마이그레이션이 간단합니다.

### 4) OpenRouter Edge Function 구현

```typescript
// supabase/functions/openrouter-chat/index.ts
// OpenRouter API 호출 — OpenAI SDK 호환 방식

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import OpenAI from 'https://deno.land/x/openai@v4.24.0/mod.ts';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { messages, complexity } = await req.json();

  // 복잡도에 따른 모델 자동 선택
  const model = complexity === 'high'
    ? 'anthropic/claude-sonnet-4-5'   // 복잡한 분석
    : 'openai/gpt-4o-mini';           // 일반 요청

  // OpenAI SDK를 OpenRouter와 함께 사용 (baseURL만 교체)
  const openai = new OpenAI({
    apiKey: Deno.env.get('OPENROUTER_API_KEY')!,
    baseURL: 'https://openrouter.ai/api/v1',
    defaultHeaders: {
      // OpenRouter 권장 헤더 — 사용 현황 모니터링용
      'HTTP-Referer': Deno.env.get('SITE_URL') ?? '',
      'X-Title': 'MyApp',
    },
  });

  const stream = await openai.chat.completions.create({
    model,
    messages,
    stream: true,
    max_tokens: 1000,
  });

  // SSE 스트리밍 응답 (8장 패턴 동일)
  const encoder = new TextEncoder();
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const content = chunk.choices[0]?.delta?.content || '';
        if (content) {
          controller.enqueue(encoder.encode(`data: ${JSON.stringify({ content, model })}\n\n`));
        }
        if (chunk.choices[0]?.finish_reason === 'stop') {
          controller.enqueue(encoder.encode('data: [DONE]\n\n'));
          controller.close();
        }
      }
    },
  });

  return new Response(readable, {
    headers: { ...corsHeaders, 'Content-Type': 'text/event-stream' },
  });
});
```

### 2) Claude API 연동 Edge Function

```typescript
// supabase/functions/claude-analyze/index.ts
// Anthropic Claude API — 장문 문서 분석에 특화

import Anthropic from 'https://esm.sh/@anthropic-ai/sdk@0.24.3';

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { document, analysisType } = await req.json();

  const client = new Anthropic({
    apiKey: Deno.env.get('ANTHROPIC_API_KEY')!,
  });

  // 분석 유형별 시스템 프롬프트 분기
  const systemPrompts: Record<string, string> = {
    legal: `당신은 법률 문서 전문 분석가입니다.
계약서, 약관, 법령을 검토하고 다음을 식별하세요:
1. 주요 조항 요약
2. 잠재적 위험 조항 (적색 표시)
3. 누락된 표준 조항
4. 권장 수정 사항
반드시 JSON 형식으로 응답하세요.`,

    financial: `당신은 재무 문서 분석 전문가입니다.
재무제표, 사업계획서를 분석하고 다음을 제공하세요:
1. 핵심 재무 지표 요약
2. 강점과 위험 요소
3. 업계 평균 대비 평가
JSON 형식으로 응답하세요.`,

    general: `당신은 문서 분석 전문가입니다.
문서를 분석하고 핵심 내용을 구조화하세요.
JSON 형식으로 응답하세요.`,
  };

  // Claude API 호출 (스트리밍)
  const stream = await client.messages.stream({
    model: 'claude-sonnet-4-5',
    max_tokens: 2000,
    system: systemPrompts[analysisType] || systemPrompts.general,
    messages: [
      {
        role: 'user',
        content: `다음 문서를 분석해 주세요:\n\n${document}`,
      },
    ],
  });

  // Anthropic 스트림 → SSE 변환
  const encoder = new TextEncoder();
  const readable = new ReadableStream({
    async start(controller) {
      for await (const event of stream) {
        if (event.type === 'content_block_delta' &&
            event.delta.type === 'text_delta') {
          controller.enqueue(
            encoder.encode(`data: ${JSON.stringify({ text: event.delta.text })}\n\n`)
          );
        }
        if (event.type === 'message_stop') {
          controller.enqueue(encoder.encode('data: [DONE]\n\n'));
          controller.close();
        }
      }
    },
  });

  return new Response(readable, {
    headers: { ...corsHeaders, 'Content-Type': 'text/event-stream' },
  });
});
```

### 3) Claude + Supabase Vector — RAG(검색 증강 생성) 기초

RAG(Retrieval-Augmented Generation)는 AI가 자체 학습 데이터 대신 사용자의 실제 문서 데이터를 참조하여 답변을 생성하는 기법입니다:

```typescript
// RAG 구현 흐름 (러버블 프롬프트 요청 예시)

/*
Claude + Supabase pgvector로 RAG 시스템을 구현해 주세요.

흐름:
1. 문서 업로드 시 텍스트를 청크(500자 단위)로 분할
2. OpenAI text-embedding-3-small로 각 청크를 벡터로 변환
3. Supabase pgvector 테이블에 저장
4. 사용자 질문 입력 시 질문을 벡터로 변환
5. 코사인 유사도로 가장 관련 있는 청크 5개 검색
6. 검색된 청크를 컨텍스트로 Claude에게 전달
7. Claude가 근거 있는 답변 생성

Supabase에서 pgvector 확장을 활성화하고
documents_embeddings 테이블을 생성해 주세요.
*/

// Supabase pgvector 테이블 생성 SQL
const pgvectorSQL = `
-- pgvector 확장 활성화
CREATE EXTENSION IF NOT EXISTS vector;

-- 임베딩 저장 테이블
CREATE TABLE document_chunks (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_id UUID REFERENCES documents ON DELETE CASCADE,
  content     TEXT NOT NULL,
  embedding   vector(1536),  -- text-embedding-3-small 차원
  chunk_index INTEGER,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 벡터 유사도 검색 인덱스 (IVFFlat)
CREATE INDEX ON document_chunks
USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);

-- 유사 청크 검색 함수
CREATE OR REPLACE FUNCTION match_chunks(
  query_embedding vector(1536),
  match_count     INTEGER DEFAULT 5,
  filter_doc_id   UUID DEFAULT NULL
)
RETURNS TABLE (id UUID, content TEXT, similarity FLOAT)
LANGUAGE plpgsql AS $$
BEGIN
  RETURN QUERY
  SELECT
    dc.id,
    dc.content,
    1 - (dc.embedding <=> query_embedding) AS similarity
  FROM document_chunks dc
  WHERE (filter_doc_id IS NULL OR dc.document_id = filter_doc_id)
  ORDER BY dc.embedding <=> query_embedding
  LIMIT match_count;
END;
$$;
`;
```

> 📝 **NOTE**
> 
> RAG는 "AI 환각(Hallucination) 방지"의 가장 효과적인 기법입니다. AI가 학습 데이터에 없는 내용을 만들어내는 대신, 사용자의 실제 문서를 실시간으로 검색하여 근거 있는 답변만 생성합니다. 사내 규정집, 제품 매뉴얼, 법률 문서 등 최신성과 정확성이 중요한 도메인에서 특히 유용합니다.

## 10.4 ElevenLabs — AI 음성 완전 연동

### 1) ElevenLabs 공식 러버블 통합

러버블은 이제 ElevenLabs를 통해 텍스트 음성 변환(TTS), 음성 텍스트 변환(STT), 에이전트, 음악 및 효과음을 네이티브로 지원합니다. 이 통합으로 누구나 음성 우선 애플리케이션을 그 어느 때보다 쉽게 만들 수 있습니다.

ElevenLabs는 러버블 앱이 고품질의 음성 및 음성 기반 경험을 생성할 수 있게 해주는 AI 오디오 플랫폼입니다. 텍스트 음성 변환, 캐릭터 음성, 또는 오디오 출력을 핵심 제품 경험으로 필요로 하는 앱을 위해 설계되었습니다.

### 3) TTS(텍스트 → 음성) 구현

```typescript
// src/hooks/useTextToSpeech.ts
// ElevenLabs TTS API 호출 — Turbo v2 모델 (150ms 이하 지연)

export function useTextToSpeech() {
  const [isLoading, setIsLoading] = useState(false);
  const [audioUrl, setAudioUrl] = useState<string | null>(null);

  const speak = async (text: string, options?: {
    voiceId?: string;    // 기본: 한국어 지원 음성
    modelId?: string;    // 기본: eleven_turbo_v2_5 (최신·저지연)
    stability?: number;  // 0~1, 높을수록 일관된 목소리
    similarityBoost?: number; // 0~1, 높을수록 원본 음성에 가까움
  }) => {
    setIsLoading(true);

    try {
      const response = await supabase.functions.invoke('elevenlabs-tts', {
        body: {
          text,
          voiceId: options?.voiceId ?? 'pNInz6obpgDQGcFmaJgB', // 기본 음성 ID
          modelId: options?.modelId ?? 'eleven_turbo_v2_5',
          stability: options?.stability ?? 0.5,
          similarityBoost: options?.similarityBoost ?? 0.75,
        },
      });

      // Base64 오디오 데이터를 Blob URL로 변환
      const audioBlob = new Blob(
        [Uint8Array.from(atob(response.data.audio), (c) => c.charCodeAt(0))],
        { type: 'audio/mpeg' }
      );
      const url = URL.createObjectURL(audioBlob);
      setAudioUrl(url);

      // 자동 재생
      const audio = new Audio(url);
      await audio.play();

    } finally {
      setIsLoading(false);
    }
  };

  return { speak, isLoading, audioUrl };
}
```

### 4) STT(음성 → 텍스트) — 음성 입력 구현

```typescript
// src/hooks/useSpeechToText.ts
// 브라우저 마이크 → ElevenLabs STT (또는 OpenAI Whisper)

export function useSpeechToText() {
  const [isRecording, setIsRecording] = useState(false);
  const [transcript, setTranscript] = useState('');
  const mediaRecorderRef = useRef<MediaRecorder | null>(null);
  const chunksRef = useRef<Blob[]>([]);

  const startRecording = async () => {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    const mediaRecorder = new MediaRecorder(stream, {
      mimeType: 'audio/webm;codecs=opus',
    });

    chunksRef.current = [];
    mediaRecorder.ondataavailable = (e) => chunksRef.current.push(e.data);

    mediaRecorder.onstop = async () => {
      const audioBlob = new Blob(chunksRef.current, { type: 'audio/webm' });

      // Base64로 변환하여 Edge Function에 전송
      const reader = new FileReader();
      reader.onload = async () => {
        const base64 = (reader.result as string).split(',')[1];
        const result = await supabase.functions.invoke('elevenlabs-stt', {
          body: { audio: base64, language: 'ko' },
        });
        setTranscript(result.data.text);
      };
      reader.readAsDataURL(audioBlob);

      // 스트림 종료
      stream.getTracks().forEach((t) => t.stop());
    };

    mediaRecorder.start();
    mediaRecorderRef.current = mediaRecorder;
    setIsRecording(true);
  };

  const stopRecording = () => {
    mediaRecorderRef.current?.stop();
    setIsRecording(false);
  };

  return { isRecording, transcript, startRecording, stopRecording };
}
```

// supabase/functions/generate-image/index.ts
// Replicate API + FLUX.1 모델로 이미지 생성

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { prompt, style, width = 1024, height = 1024 } = await req.json();

  // 스타일 프리셋

    realistic: 'photorealistic, 8k, high detail, professional photography',
    illustration: 'digital illustration, flat design, vibrant colors, clean lines',
    anime: 'anime style, Studio Ghibli inspired, detailed, colorful',
    product: 'product photography, white background, studio lighting, commercial',
    korean_art: '한국 전통 수묵화 스타일, 먹과 선, 여백의 미',
  };

  const fullPrompt = style
    ? `${prompt}, ${stylePrompts[style] || ''}`
    : prompt;

  // Replicate API 호출 — FLUX.1 schnell 모델
  const response = await fetch('https://api.replicate.com/v1/models/black-forest-labs/flux-schnell/predictions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${Deno.env.get('REPLICATE_API_TOKEN')}`,
      'Content-Type': 'application/json',
      'Prefer': 'wait',  // 결과 완료까지 대기 (최대 60초)
    },
    body: JSON.stringify({
      input: {
        prompt: fullPrompt,
        width,
        height,
        num_outputs: 1,
        num_inference_steps: 4,   // schnell: 4단계로 빠른 생성
        output_format: 'webp',
        output_quality: 90,
      },
    }),
  });

  if (!response.ok) {
    const err = await response.json();
    throw new Error(`Replicate 오류: ${JSON.stringify(err)}`);
  }

  const prediction = await response.json();

  // 생성된 이미지 URL 반환
  const imageUrl = prediction.output?.[0];
  if (!imageUrl) throw new Error('이미지 생성 실패');

  // 생성된 이미지를 Supabase Storage에 저장 (영구 보관)
  const imageResponse = await fetch(imageUrl);
  const imageBuffer = await imageResponse.arrayBuffer();
  const fileName = `generated/${Date.now()}.webp`;

  const supabase = createClient(/* ... */);
  const { data } = await supabase.storage
    .from('images')
    .upload(fileName, imageBuffer, { contentType: 'image/webp' });

  const { data: { publicUrl } } = supabase.storage
    .from('images')
    .getPublicUrl(fileName);

  return new Response(
    JSON.stringify({ imageUrl: publicUrl, prompt: fullPrompt }),
    { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
  );
});

> OpenRouter로 500개 모델을 단일 API로 통합하고, 복잡도에 따라 모델을 자동 선택하는 라우팅 전략을 구사하세요. 음성이 필요하면 ElevenLabs, 이미지가 필요하면 Replicate, 최신 정보가 필요하면 Perplexity를 연결하면 됩니다. 러버블의 커넥터 시스템은 이 모든 서비스를 API 키 하나로 안전하게 연결합니다. 비용 관리를 위해 반드시 각 서비스의 지출 한도를 설정하고, 동일한 응답은 캐싱하는 습관을 들이세요.
