```
[DocSense AI 파이프라인]

① 사용자가 PDF 또는 이미지 파일 업로드
           ↓
② Supabase Storage에 파일 저장
           ↓
③ 파일 유형 분기
   ├── PDF → PDF.js로 텍스트 직접 추출

           ↓

           ↓
⑤ OpenAI GPT-4o → 문서 요약(Summary) 생성
           ↓
⑥ 요약 결과 → analyses 테이블 저장 + 화면 표시
           ↓
⑦ 사용자가 Q&A 채팅 입력
           ↓
⑧ OpenAI GPT-4o (스트리밍) → 실시간 답변 생성
           ↓
⑨ 대화 히스토리 → chat_messages 테이블 저장
```

### 3) Supabase DB 스키마

```sql
-- 문서 테이블
CREATE TABLE documents (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID REFERENCES auth.users NOT NULL,
  title       TEXT NOT NULL,
  file_url    TEXT,
  file_type   TEXT,              -- 'pdf', 'image', 'text'
  raw_text    TEXT,              -- 추출된 원문 텍스트
  page_count  INTEGER,
  status      TEXT DEFAULT 'pending', -- 'pending'|'processing'|'done'|'error'
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 분석 결과 테이블
CREATE TABLE analyses (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_id UUID REFERENCES documents ON DELETE CASCADE,
  summary     TEXT,              -- AI 요약
  key_points  JSONB,             -- 핵심 포인트 배열
  language    TEXT DEFAULT 'ko', -- 원문 언어
  model       TEXT,              -- 사용된 AI 모델
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 채팅 메시지 테이블
CREATE TABLE chat_messages (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_id UUID REFERENCES documents ON DELETE CASCADE,
  user_id     UUID REFERENCES auth.users NOT NULL,
  role        TEXT NOT NULL,     -- 'user' | 'assistant'
  content     TEXT NOT NULL,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

## 8.2 Lovable AI 네이티브 연동 — API 키 없이 AI 기능 추가

### 1) Lovable AI란?

러버블은 API 키나 별도 설정 없이 앱에 강력한 AI 기능을 추가할 수 있는 **Lovable AI** 기능을 제공합니다. AI 요약, 챗봇, 문서 Q&A, 번역, 자동화 등을 즉시 활성화할 수 있습니다.

빠른 프로토타이핑 단계에서 API 키를 발급받기 전에 Lovable AI로 AI 기능의 작동 여부를 먼저 검증한 다음, 프로덕션 단계에서 OpenAI 등 자체 API로 교체하는 전략이 효율적입니다.

**Lovable AI 활성화 방법:**

```
러버블 대시보드 → Settings → Connectors → Shared connectors
→ Lovable AI → Manage permissions
→ "Always allow" 선택
```

**Lovable AI로 즉시 구현 가능한 기능 프롬프트:**

```
Lovable AI를 사용해서 문서 요약 기능을 추가해 주세요.
사용자가 문서를 선택하면 자동으로 300자 이내 요약을 생성하고
대시보드 우측 상단에 표시해 주세요.
```

> 📝 **NOTE**
> 
> Lovable AI는 사용량 기반 과금 방식입니다. 프로토타입 검증 후에는 비용 예측이 가능한 OpenAI 직접 연동으로 전환하는 것을 권장합니다. 상업 서비스에서는 응답 품질과 비용을 정밀하게 제어할 수 있는 자체 API 연동이 유리합니다.

### 3) 문서 요약 Edge Function — GPT-4o 완전 구현

```typescript
// supabase/functions/summarize-document/index.ts
// OpenAI SDK v4 + Deno 런타임 기준

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import OpenAI from 'https://deno.land/x/openai@v4.24.0/mod.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  try {
    const { documentId } = await req.json();

    // 사용자 인증
    const supabase = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_ANON_KEY')!,
      { global: { headers: { Authorization: req.headers.get('Authorization')! } } }
    );

    const { data: { user } } = await supabase.auth.getUser();
    if (!user) throw new Error('인증이 필요합니다.');

    // 문서 조회 (본인 문서만)
    const { data: doc, error: docError } = await supabase
      .from('documents')
      .select('id, title, raw_text, status')
      .eq('id', documentId)
      .eq('user_id', user.id)
      .single();

    if (docError || !doc) throw new Error('문서를 찾을 수 없습니다.');
    if (!doc.raw_text) throw new Error('분석할 텍스트가 없습니다. 먼저 OCR을 실행해 주세요.');

    // 처리 중 상태로 업데이트
    await supabase.from('documents')
      .update({ status: 'processing' })
      .eq('id', documentId);

    // OpenAI 초기화
    const openai = new OpenAI({ apiKey: Deno.env.get('OPENAI_API_KEY')! });

    // 텍스트가 너무 길면 앞부분만 사용 (토큰 제한 대비)
    const MAX_CHARS = 12000;  // 약 3,000 토큰
    const truncatedText = doc.raw_text.length > MAX_CHARS
      ? doc.raw_text.slice(0, MAX_CHARS) + '\n\n[텍스트가 길어 일부만 분석되었습니다]'
      : doc.raw_text;

    // GPT-4o 요약 요청
    const completion = await openai.chat.completions.create({
      model: 'gpt-4o',
      messages: [
        {
          role: 'system',
          content: `당신은 전문 문서 분석가입니다. 
주어진 문서를 다음 형식으로 분석하세요:

1. 요약(Summary): 핵심 내용을 300자 이내로 명확하게 작성
2. 핵심 포인트(Key Points): 중요한 내용 5개를 배열로 제공
3. 문서 유형(Type): 보고서/논문/계약서/뉴스/기타 중 하나

반드시 JSON 형식으로만 응답하세요:
{
  "summary": "요약 내용",
  "key_points": ["포인트1", "포인트2", ...],
  "document_type": "유형"
}`,
        },
        {
          role: 'user',
          content: `문서 제목: ${doc.title}\n\n본문:\n${truncatedText}`,
        },
      ],
      response_format: { type: 'json_object' }, // JSON 모드 활성화
      max_tokens: 1000,
      temperature: 0.3,  // 낮은 온도 = 일관된 출력
    });

    // 응답 파싱
    const analysisText = completion.choices[0].message.content!;
    const analysis = JSON.parse(analysisText);

    // 분석 결과 저장
    await supabase.from('analyses').upsert({
      document_id: documentId,
      summary: analysis.summary,
      key_points: analysis.key_points,
      model: 'gpt-4o',
    });

    // 문서 상태 완료로 업데이트
    await supabase.from('documents')
      .update({ status: 'done' })
      .eq('id', documentId);

    return new Response(
      JSON.stringify({ success: true, analysis }),
      { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );

  } catch (error) {
    // 오류 시 상태 원복
    return new Response(
      JSON.stringify({ error: error.message }),
      { status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  }
});
```

### 4) 스트리밍 Q&A 채팅 구현

스트리밍(Streaming)은 AI 응답을 한 번에 받는 것이 아니라 **생성되는 즉시 단어 단위로 전송**하는 방식입니다. ChatGPT처럼 타이핑되듯 나타나는 효과를 구현합니다.

**스트리밍 Edge Function:**

```typescript
// supabase/functions/chat-with-document/index.ts
// Server-Sent Events (SSE) 스트리밍 구현

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { documentId, message, history } = await req.json();

  // 인증 및 문서 조회 (위와 동일 패턴)...

  const openai = new OpenAI({ apiKey: Deno.env.get('OPENAI_API_KEY')! });

  // 스트리밍 응답 생성
  const stream = await openai.chat.completions.create({
    model: 'gpt-4o-mini',  // Q&A에는 mini 모델로 비용 절감
    stream: true,           // 스트리밍 활성화
    messages: [
      {
        role: 'system',
        content: `당신은 문서 분석 도우미입니다.
아래 문서 내용을 바탕으로 사용자의 질문에 답변하세요.
문서에 없는 내용은 "문서에서 해당 정보를 찾을 수 없습니다"라고 명확히 말하세요.

[문서 내용]
${doc.raw_text?.slice(0, 8000)}`,
      },
      // 이전 대화 히스토리 포함 (멀티턴 대화)
      ...history.map((msg: any) => ({
        role: msg.role,
        content: msg.content,
      })),
      { role: 'user', content: message },
    ],
    max_tokens: 800,
  });

  // SSE(Server-Sent Events) 스트림으로 변환하여 반환
  const encoder = new TextEncoder();
  const readable = new ReadableStream({
    async start(controller) {
      let fullContent = '';

      for await (const chunk of stream) {
        const content = chunk.choices[0]?.delta?.content || '';
        if (content) {
          fullContent += content;
          // SSE 형식: "data: [내용]\n\n"
          controller.enqueue(encoder.encode(`data: ${JSON.stringify({ content })}\n\n`));
        }

        // 스트림 완료
        if (chunk.choices[0]?.finish_reason === 'stop') {
          // 완성된 메시지 DB 저장
          await supabase.from('chat_messages').insert([
            { document_id: documentId, user_id: user.id, role: 'user', content: message },
            { document_id: documentId, user_id: user.id, role: 'assistant', content: fullContent },
          ]);
          controller.enqueue(encoder.encode('data: [DONE]\n\n'));
          controller.close();
        }
      }
    },
  });

  return new Response(readable, {
    headers: {
      ...corsHeaders,
      'Content-Type': 'text/event-stream',
      'Cache-Control': 'no-cache',
      'Connection': 'keep-alive',
    },
  });
});
```

**프론트엔드 스트리밍 수신 훅:**

```typescript
// src/hooks/useStreamingChat.ts
// SSE 스트리밍 응답을 실시간으로 UI에 반영

import { useState } from 'react';
import { supabase } from '@/integrations/supabase/client';

export function useStreamingChat(documentId: string) {
  const [streamingContent, setStreamingContent] = useState('');
  const [isStreaming, setIsStreaming] = useState(false);

  const sendMessage = async (message: string, history: any[]) => {
    setIsStreaming(true);
    setStreamingContent('');

    const { data: { session } } = await supabase.auth.getSession();

    // Edge Function 호출 (fetch API로 스트리밍 수신)
    const response = await fetch(
      `${import.meta.env.VITE_SUPABASE_URL}/functions/v1/chat-with-document`,
      {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${session?.access_token}`,
        },
        body: JSON.stringify({ documentId, message, history }),
      }
    );

    if (!response.body) throw new Error('스트리밍 응답이 없습니다.');

    // SSE 스트림 읽기
    const reader = response.body.getReader();
    const decoder = new TextDecoder();

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      const lines = decoder.decode(value).split('\n');
      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const data = line.slice(6);
          if (data === '[DONE]') {
            setIsStreaming(false);
            break;
          }
          try {
            const { content } = JSON.parse(data);
            // 스트리밍 콘텐츠 누적
            setStreamingContent((prev) => prev + content);
          } catch { /* JSON 파싱 오류 무시 */ }
        }
      }
    }
  };

  return { streamingContent, isStreaming, sendMessage };
}
```

**스트리밍 채팅 UI 컴포넌트:**

```typescript
// src/components/ChatInterface.tsx
import { useState } from 'react';
import { useStreamingChat } from '@/hooks/useStreamingChat';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';

const ChatInterface = ({ documentId }: { documentId: string }) => {
  const [messages, setMessages] = useState<Array<{role: string; content: string}>>([]);
  const [input, setInput] = useState('');
  const { streamingContent, isStreaming, sendMessage } = useStreamingChat(documentId);

  const handleSend = async () => {
    if (!input.trim() || isStreaming) return;

    const userMessage = { role: 'user', content: input };
    setMessages((prev) => [...prev, userMessage]);
    setInput('');

    await sendMessage(input, messages);

    // 스트리밍 완료 후 메시지 목록에 추가
    setMessages((prev) => [
      ...prev,
      { role: 'assistant', content: streamingContent },
    ]);
  };

  return (
    <div className="flex flex-col h-full">
      {/* 메시지 목록 */}
      <div className="flex-1 overflow-auto p-4 space-y-4">
        {messages.map((msg, i) => (
          <div key={i} className={`flex ${msg.role === 'user' ? 'justify-end' : 'justify-start'}`}>
            <div className={`max-w-[80%] rounded-2xl px-4 py-3 text-sm
              ${msg.role === 'user'
                ? 'bg-indigo-600 text-white'
                : 'bg-gray-100 text-gray-900'}`}>
              {msg.content}
            </div>
          </div>
        ))}

        {/* 스트리밍 중인 응답 실시간 표시 */}
        {isStreaming && (
          <div className="flex justify-start">
            <div className="max-w-[80%] rounded-2xl px-4 py-3 bg-gray-100 text-sm text-gray-900">
              {streamingContent}
              {/* 타이핑 커서 애니메이션 */}
              <span className="inline-block w-1 h-4 bg-gray-400 ml-1 animate-pulse" />
            </div>
          </div>
        )}
      </div>

      {/* 입력창 */}
      <div className="border-t p-4 flex gap-2">
        <Input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && !e.shiftKey && handleSend()}
          placeholder="문서에 대해 질문해 보세요..."
          disabled={isStreaming}
          className="flex-1"
        />
        <Button
          onClick={handleSend}
          disabled={isStreaming || !input.trim()}
          className="bg-indigo-600 hover:bg-indigo-700"
        >
          {isStreaming ? '답변 중...' : '전송'}
        </Button>
      </div>
    </div>
  );
};
```

## 8.4 [한국어 특화] 네이버 CLOVA OCR 연동

### 1) CLOVA OCR 개요

**CLOVA OCR**은 네이버의 AI 기술을 활용하여 주요 비즈니스 활용에 최적화된 고성능 OCR 인식 모델을 적용한 서비스입니다. 문자 인식은 한국어, 영어, 일본어를 지원하며, RESTful API 방식으로 이미지를 입력받아 인식 결과를 텍스트로 반환합니다.

한국어 문서 인식에서는 Google Cloud Vision이나 AWS Textract보다 CLOVA OCR의 정확도가 높습니다. 특히 영수증, 사업자등록증, 명함, 신분증 등 **특화 문서 모델(Document OCR)** 을 제공하여 정형화된 한국어 문서에서 탁월한 성능을 발휘합니다.

---

### 2) CLOVA OCR 3가지 서비스 유형

CLOVA OCR은 세 가지 서비스 유형을 제공합니다. **General OCR**은 이미지나 문서에서 범용적으로 텍스트를 추출하며, **Template OCR**은 특정 양식의 문서에서 지정 영역의 텍스트만 정확하게 추출하고, **Document OCR**은 영수증, 신용카드, 사업자등록증, 명함, 신분증 등 특화 문서의 주요 정보를 구조화된 형태로 반환합니다.

|유형|용도|특징|
|---|---|---|
|**General OCR**|일반 문서·사진|이미지 내 모든 텍스트 추출|
|**Template OCR**|정형화된 양식 문서|사용자가 지정한 영역만 추출|
|**Document OCR**|영수증·명함·신분증 등|특화 모델, 구조화된 JSON 반환|

---

### 3) CLOVA OCR 설정 단계별 가이드

**① 네이버 클라우드 플랫폼 설정**

```
1. https://www.ncloud.com 접속 → 로그인
2. Console → Services → AI Services → CLOVA OCR
3. 이용 신청하기 → 약관 동의
4. OCR 빌더 → 도메인 생성
   - 도메인 이름: docsense-general
   - 서비스 타입: General (범용 텍스트 추출)
   - 지원 언어: 한국어 (영어 자동 포함)
5. API Gateway 자동 연동 클릭

> ⚠️ **WARNING**
> 
> CLOVA OCR은 기본적으로 유료 서비스입니다. 개발 중 과도한 API 호출로 예상치 못한 과금이 발생할 수 있으므로 무료 구간(월 1,000회)을 확인하고 개발하세요. 또한 API 호출 시 CORS 오류가 발생할 수 있는데, 이는 API Gateway에 `x-ocr-secret` 헤더를 CORS 허용 헤더로 추가해야 해결됩니다.

```

### 4) CLOVA OCR Edge Function 구현

```typescript
// supabase/functions/extract-text-ocr/index.ts
// 네이버 CLOVA OCR API 호출 (Text OCR 기준)

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  try {
    const { imageUrl, documentId } = await req.json();

    // 인증 확인...

    // CLOVA OCR API 요청 본문
    // https://guide.ncloud-docs.com/docs/clovaocr-example01 참고
    const requestBody = {
      images: [
        {
          format: imageUrl.split('.').pop()?.toLowerCase() || 'jpg',  // 'jpg', 'png', 'pdf'
          name: `doc-${documentId}`,
          url: imageUrl,   // Supabase Storage 공개 URL
        },
      ],
      lang: 'ko',          // 한국어 우선 인식
      requestId: crypto.randomUUID(),
      timestamp: Date.now(),
      version: 'V2',
    };

    // CLOVA OCR API 호출
    const ocrResponse = await fetch(
      Deno.env.get('CLOVA_OCR_INVOKE_URL')!,
      {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'X-OCR-SECRET': Deno.env.get('CLOVA_OCR_SECRET')!,
        },
        body: JSON.stringify(requestBody),
      }
    );

    if (!ocrResponse.ok) {
      const errText = await ocrResponse.text();
      throw new Error(`CLOVA OCR 오류: ${errText}`);
    }

    const ocrResult = await ocrResponse.json();

    // OCR 결과에서 텍스트 추출
    // 응답 구조: result.images[0].fields[].inferText
    const extractedText = ocrResult.images?.[0]?.fields
      ?.map((field: any) => field.inferText)
      ?.join(' ')
      ?? '';

    if (!extractedText) throw new Error('텍스트를 추출할 수 없습니다.');

    // Supabase에 추출된 텍스트 저장
    const supabase = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
    );

    await supabase.from('documents')
      .update({
        raw_text: extractedText,
        status: 'pending',  // 요약 단계로 이동 준비
      })
      .eq('id', documentId);

    return new Response(
      JSON.stringify({ success: true, text: extractedText, length: extractedText.length }),
      { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );

  } catch (error) {
    return new Response(
      JSON.stringify({ error: error.message }),
      { status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  }
});
```

## 8.5 AI 처리 파이프라인 — 전체 오케스트레이션

### 1) 단계별 처리 흐름 구현

파일 업로드 후 OCR → 요약까지 이어지는 전체 파이프라인을 하나의 훅으로 관리합니다:

```typescript
// src/hooks/useDocumentPipeline.ts
// 문서 처리 파이프라인 전체 관리

import { useState } from 'react';
import { supabase } from '@/integrations/supabase/client';
import { useToast } from '@/hooks/use-toast';

type PipelineStatus = 'idle' | 'uploading' | 'ocr' | 'summarizing' | 'done' | 'error';

export function useDocumentPipeline() {
  const [status, setStatus] = useState<PipelineStatus>('idle');
  const [progress, setProgress] = useState(0);  // 0~100
  const { toast } = useToast();

  const processDocument = async (file: File) => {
    try {
      // 단계 1: 파일 업로드 (0~30%)
      setStatus('uploading');
      setProgress(10);

      const fileExt = file.name.split('.').pop();
      const filePath = `${crypto.randomUUID()}.${fileExt}`;

      const { error: uploadError } = await supabase.storage
        .from('documents')
        .upload(filePath, file);

      if (uploadError) throw uploadError;
      setProgress(30);

      // 공개 URL 획득
      const { data: { publicUrl } } = supabase.storage
        .from('documents')
        .getPublicUrl(filePath);

      // DB에 문서 레코드 생성
      const { data: doc, error: docError } = await supabase
        .from('documents')
        .insert({
          title: file.name,
          file_url: publicUrl,
          file_type: fileExt === 'pdf' ? 'pdf' : 'image',
          status: 'pending',
        })
        .select()
        .single();

      if (docError) throw docError;
      setProgress(40);

      // 단계 2: 이미지 파일은 OCR 실행 (30~60%)
      if (['jpg', 'jpeg', 'png', 'webp'].includes(fileExt || '')) {
        setStatus('ocr');
        const { error: ocrError } = await supabase.functions.invoke('extract-text-ocr', {
          body: { imageUrl: publicUrl, documentId: doc.id },
        });
        if (ocrError) throw ocrError;
        setProgress(60);
      } else {
        // PDF는 별도 텍스트 추출 로직 사용
        setProgress(60);
      }

      // 단계 3: AI 요약 (60~100%)
      setStatus('summarizing');
      const { error: summaryError } = await supabase.functions.invoke('summarize-document', {
        body: { documentId: doc.id },
      });
      if (summaryError) throw summaryError;

      setProgress(100);
      setStatus('done');

      toast({
        title: '분석 완료!',
        description: `"${file.name}" 문서가 성공적으로 분석되었습니다.`,
      });

      return doc.id;

    } catch (error: any) {
      setStatus('error');
      toast({
        title: '처리 실패',
        description: error.message,
        variant: 'destructive',
      });
    }
  };

  return { status, progress, processDocument };
}
```
