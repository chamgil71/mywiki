## 7.2 랜딩 페이지와 가격 플랜 UI 제작

### 1) 가격 플랜 컴포넌트 핵심 구조

```typescript
// src/components/PricingCard.tsx
// 가격 플랜 카드 컴포넌트

interface PricingPlan {
  name: string;
  price: string;
  period: string;

  highlighted: boolean;  // 추천 플랜 강조 표시

const PricingCard = ({ plan }: { plan: PricingPlan }) => (
  <div className={`relative rounded-2xl p-8 border-2 transition-all
    ${plan.highlighted
      ? 'border-violet-600 bg-violet-50 shadow-xl scale-105'  // 추천 플랜
      : 'border-gray-200 bg-white hover:border-violet-300'
    }`}>

    {/* 추천 배지 */}
    {plan.highlighted && (
      <span className="absolute -top-4 left-1/2 -translate-x-1/2
                       bg-violet-600 text-white text-sm font-medium
                       px-4 py-1 rounded-full">
        가장 인기
      </span>
    )}

    <h3 className="text-xl font-bold text-gray-900">{plan.name}</h3>
    <div className="mt-4 flex items-baseline gap-1">
      <span className="text-4xl font-extrabold text-gray-900">{plan.price}</span>
      <span className="text-gray-500">/{plan.period}</span>
    </div>
    <p className="mt-2 text-gray-600 text-sm">{plan.description}</p>

    {/* 기능 목록 */}
    <ul className="mt-6 space-y-3">
      {plan.features.map((feature, i) => (
        <li key={i} className="flex items-center gap-2 text-sm">
          <span className="text-violet-600 font-bold">✓</span>
          <span className="text-gray-700">{feature}</span>
```

> 💡 **TIP**
> 
> 가격 플랜 카드에서 **"가장 인기" 배지가 붙은 중간 플랜을 약간 크게 표시**하는 것은 전환율을 높이는 검증된 UI 패턴입니다. 사용자는 중간 플랜을 합리적인 선택으로 인식합니다. 러버블에 "중간 플랜 카드를 `scale-105`로 약간 크게, 외곽선을 강조 색상으로 변경해줘"라고 요청하면 바로 적용됩니다.

## 7.3 Stripe 결제 완전 연동

### 1) Stripe 개요와 러버블 채팅 기반 자동 연동

러버블은 Supabase와 Stripe API 키를 연결하면 채팅 한 줄로 결제 기능 전체를 자동 생성합니다. 체크아웃 Edge Function, DB 테이블(RLS 포함), UI 버튼까지 자동으로 만들어 주며 수동 웹훅 설정도 필요 없습니다.

**연동 사전 조건:**

- Supabase 프로젝트 연결 완료
- Stripe 계정 생성 ([https://stripe.com](https://stripe.com/))
- Stripe 대시보드에서 상품(Product) 및 가격(Price) 생성 완료

### 6) 체크아웃 세션 생성 Edge Function

```typescript
// supabase/functions/create-checkout-session/index.ts
// Deno 런타임 + Stripe JS v14 기준

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import Stripe from 'https://esm.sh/stripe@14.21.0?target=deno';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  try {
    const { priceId } = await req.json();

    // 사용자 인증 확인
    const supabase = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_ANON_KEY')!,
      { global: { headers: { Authorization: req.headers.get('Authorization')! } } }
    );

    const { data: { user }, error: authError } = await supabase.auth.getUser();
    if (authError || !user) throw new Error('인증이 필요합니다.');

    // Stripe 초기화
    const stripe = new Stripe(Deno.env.get('STRIPE_SECRET_KEY')!, {
      apiVersion: '2024-06-20',
    });

    // 기존 Stripe 고객 조회 또는 신규 생성
    const { data: profile } = await supabase
      .from('profiles')
      .select('stripe_customer_id, full_name')
      .eq('id', user.id)
      .single();

    let customerId = profile?.stripe_customer_id;
    if (!customerId) {
      const customer = await stripe.customers.create({
        email: user.email!,
        name: profile?.full_name || '',
        metadata: { supabase_user_id: user.id },
      });
      customerId = customer.id;

      // 고객 ID 저장
      await supabase
        .from('profiles')
        .update({ stripe_customer_id: customerId })
        .eq('id', user.id);
    }

    // 체크아웃 세션 생성
    const session = await stripe.checkout.sessions.create({
      customer: customerId,
      mode: 'subscription',         // 구독 모드
      payment_method_types: ['card'],
      line_items: [{ price: priceId, quantity: 1 }],
      success_url: `${Deno.env.get('SITE_URL')}/payment/success?session_id={CHECKOUT_SESSION_ID}`,
      cancel_url: `${Deno.env.get('SITE_URL')}/payment/cancel`,
      subscription_data: {
        metadata: { supabase_user_id: user.id }, // 웹훅에서 사용자 식별용
      },
      // 한국어 설정
      locale: 'ko',
      // 프로모션 코드 허용
      allow_promotion_codes: true,
    });

    return new Response(
      JSON.stringify({ url: session.url }),
      { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );

  } catch (error) {
    return new Response(
      JSON.stringify({ error: error.message }),
      { status: 400, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  }
});
```

### 7) 웹훅(Webhook) 설정

웹훅은 Stripe에서 결제 이벤트 발생 시 서버에 자동 알림을 보내는 기능입니다.

> 📝 **NOTE**
> 
> 러버블은 기본적으로 Edge Function 폴링(Polling) 방식을 사용하며 웹훅은 옵트인(Opt-in)입니다. 단순한 일회성 결제는 폴링으로 충분하지만, 구독 갱신·취소·결제 실패 같은 비동기 이벤트는 반드시 웹훅을 통해 처리해야 합니다.

**웹훅 등록 방법:**

```
① Supabase Edge Function 배포 후 엔드포인트 URL 확인:
   https://[프로젝트ID].supabase.co/functions/v1/stripe-webhook

② Stripe 대시보드 → 개발자 → 웹훅 → 엔드포인트 추가
   - URL: 위 Edge Function URL 입력
   - 수신할 이벤트:
     ✓ checkout.session.completed
     ✓ customer.subscription.updated
     ✓ customer.subscription.deleted
     ✓ invoice.payment_failed

③ 웹훅 시크릿(Signing Secret) 복사
   → Supabase → Edge Functions → Manage Secrets →
     STRIPE_WEBHOOK_SECRET = whsec_... 등록
```

**웹훅 처리 Edge Function:**

```typescript
// supabase/functions/stripe-webhook/index.ts

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import Stripe from 'https://esm.sh/stripe@14.21.0?target=deno';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

serve(async (req) => {
  const signature = req.headers.get('stripe-signature')!;
  const body = await req.text();

  const stripe = new Stripe(Deno.env.get('STRIPE_SECRET_KEY')!, {
    apiVersion: '2024-06-20',
  });

  // 웹훅 서명 검증 (필수 — 위조 요청 방지)
  let event: Stripe.Event;
  try {
    event = stripe.webhooks.constructEvent(
      body,
      signature,
      Deno.env.get('STRIPE_WEBHOOK_SECRET')!
    );
  } catch {
    return new Response('웹훅 서명 검증 실패', { status: 400 });
  }

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')! // 서비스 롤 키 (RLS 우회 필요)
  );

  // 이벤트 유형별 처리
  switch (event.type) {

    case 'checkout.session.completed': {
      const session = event.data.object as Stripe.Checkout.Session;
      const userId = session.subscription_data?.metadata?.supabase_user_id;
      if (!userId) break;

      // 구독 정보 조회
      const subscription = await stripe.subscriptions.retrieve(
        session.subscription as string
      );

      // subscriptions 테이블 저장
      await supabase.from('subscriptions').upsert({
        user_id: userId,
        stripe_customer_id: session.customer as string,
        stripe_subscription_id: subscription.id,
        plan: subscription.items.data[0].price.lookup_key || 'pro',
        status: subscription.status,
        current_period_end: new Date(subscription.current_period_end * 1000).toISOString(),
      });

      // 프로필 플랜 업데이트
      await supabase.from('profiles')
        .update({ plan: 'pro' })
        .eq('id', userId);
      break;
    }

    case 'customer.subscription.deleted': {
      const subscription = event.data.object as Stripe.Subscription;
      const userId = subscription.metadata?.supabase_user_id;
      if (!userId) break;

      // 플랜을 무료로 다운그레이드
      await supabase.from('profiles')
        .update({ plan: 'free' })
        .eq('id', userId);

      await supabase.from('subscriptions')
        .update({ status: 'canceled' })
        .eq('stripe_subscription_id', subscription.id);
      break;
    }

    case 'invoice.payment_failed': {
      const invoice = event.data.object as Stripe.Invoice;
      // 결제 실패 처리 — 이메일 알림 발송 등
      console.log(`결제 실패: 고객 ${invoice.customer}`);
      break;
    }
  }

  return new Response(JSON.stringify({ received: true }), {
    headers: { 'Content-Type': 'application/json' }
  });
});
```

> ⚠️ **WARNING**
> 
> 웹훅 처리 Edge Function에서는 **서비스 롤 키(SUPABASE_SERVICE_ROLE_KEY)** 를 사용합니다. 이 키는 RLS를 우회하여 모든 테이블에 접근할 수 있으므로 Edge Function 환경변수에만 저장하고 절대 프론트엔드 코드에 포함시켜서는 안 됩니다. 또한 Stripe 연동은 프리뷰 환경에서는 작동하지 않습니다. 반드시 배포 후 테스트하세요.

### 3) 토스페이먼츠 결제 위젯 연동

러버블이 자동 생성하지 않는 경우 다음 프롬프트로 직접 구현을 요청합니다:

```
토스페이먼츠 결제 위젯을 연동해 주세요.

- SDK: @tosspayments/tosspayments-sdk (npm)
- 클라이언트 키: 환경변수 VITE_TOSS_CLIENT_KEY에서 로드
- 결제 금액: 19000 (Pro 플랜 월 구독, 원화)
- 결제 성공: /payment/success?paymentKey=...&orderId=...&amount=...
- 결제 실패: /payment/cancel?code=...&message=...
- 결제창은 /checkout 페이지에 위젯으로 삽입 (리디렉션 방식 아님)
- 약관 동의 UI도 위젯으로 함께 표시
```

**토스페이먼츠 결제 승인 Edge Function:**

```typescript
// supabase/functions/toss-confirm-payment/index.ts
// 토스페이먼츠 결제 승인 API 호출

serve(async (req) => {
  const { paymentKey, orderId, amount } = await req.json();

  // 시크릿 키를 Base64로 인코딩 (토스페이먼츠 인증 방식)
  const secretKey = Deno.env.get('TOSS_SECRET_KEY')!;
  const encodedKey = btoa(secretKey + ':');  // 콜론을 붙인 후 Base64 인코딩

  // 결제 승인 API 호출
  const response = await fetch(
    'https://api.tosspayments.com/v1/payments/confirm',
    {
      method: 'POST',
      headers: {
        'Authorization': `Basic ${encodedKey}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ paymentKey, orderId, amount }),
    }
  );

  const payment = await response.json();

  if (!response.ok) {
    return new Response(
      JSON.stringify({ error: payment.message }),
      { status: 400 }
    );
  }

  // 결제 성공: DB에 결제 내역 저장
  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  await supabase.from('payment_history').insert({
    order_id: orderId,
    amount,
    payment_key: paymentKey,
    method: payment.method,
    status: payment.status,
    currency: 'KRW',
  });

  // 프로필 플랜 업데이트
  // (주의: 실제 구독 관리는 웹훅으로 처리 권장)
  await supabase.from('profiles')
    .update({ plan: 'pro' })
    .eq('id', /* 현재 사용자 ID */);

  return new Response(
    JSON.stringify({ success: true, payment }),
    { headers: { 'Content-Type': 'application/json' } }
  );
});
```

### 4) 토스페이먼츠 웹훅 처리

토스페이먼츠 웹훅은 결제 상태가 변경되었을 때 실시간으로 알림을 받는 기능입니다. 개발자센터 웹훅 메뉴에서 웹훅 이름과 엔드포인트 URL을 입력하고 수신할 이벤트를 선택하면 등록됩니다.

```typescript
// supabase/functions/toss-webhook/index.ts
// 토스페이먼츠 웹훅 처리

serve(async (req) => {
  const body = await req.json();
  const { eventType, data } = body;

  // 웹훅 서명 검증 (HMAC-SHA256)
  const signature = req.headers.get('Toss-Signature');
  // 서명 검증 로직 (토스페이먼츠 문서 참고)

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  switch (eventType) {
    case 'PAYMENT_STATUS_CHANGED':
      // 결제 상태 변경 처리
      if (data.status === 'DONE') {
        await supabase.from('payment_history')
          .update({ status: 'DONE' })
          .eq('order_id', data.orderId);
      }
      break;

    case 'DEPOSIT_CALLBACK':
      // 가상계좌 입금 처리
      if (data.status === 'DONE') {
        // 서비스 제공 로직
      }
      break;
  }

  return new Response(JSON.stringify({ ok: true }));
});
```

> 📝 **NOTE**
> 
> 토스페이먼츠는 국내 서비스이므로 **사업자 등록증**이 있어야 실제 결제(라이브 모드)를 사용할 수 있습니다. 개인 사업자 또는 법인 사업자 모두 가능합니다. 사업자 등록 없이 테스트만 하는 경우에는 `test_ck_...` / `test_sk_...` 키로 모든 기능을 체험할 수 있습니다.

## 7.5 구독 등급별 기능 제어 구현

### 1) 플랜별 접근 제어 훅

```typescript
// src/hooks/usePlanAccess.ts — 플랜별 기능 접근 제어

import { useAuth } from '@/hooks/useAuth';

type Feature =
  | 'unlimited_generation'  // 무제한 AI 생성
  | 'export_docx'           // DOCX 내보내기
  | 'export_pdf'            // PDF 내보내기 (Team 전용)
  | 'history'               // 히스토리 보관
  | 'team_features';        // 팀 기능

// 플랜별 허용 기능 정의
const PLAN_FEATURES: Record<string, Feature[]> = {
  free: [],
  pro: ['unlimited_generation', 'export_docx', 'history'],
  team: ['unlimited_generation', 'export_docx', 'export_pdf', 'history', 'team_features'],
};

export function usePlanAccess() {
  const { user } = useAuth();
  const plan = user?.user_metadata?.plan || 'free';

  const hasAccess = (feature: Feature): boolean => {
    return PLAN_FEATURES[plan]?.includes(feature) ?? false;
  };

  const isFreePlan = plan === 'free';
  const isProOrAbove = ['pro', 'team'].includes(plan);
  const isTeam = plan === 'team';

  return { plan, hasAccess, isFreePlan, isProOrAbove, isTeam };
}
```
