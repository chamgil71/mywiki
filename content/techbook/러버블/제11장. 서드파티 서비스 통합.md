# 제11장. 서드파티 서비스 통합

> _"앱의 진짜 가치는 단독으로 작동하는 것이 아니라, 팀이 이미 쓰는 도구들과 매끄럽게 연결될 때 드러난다."_

## 0) 연결 고리

> 🔗 10장에서 AI 서비스 생태계를 완성했습니다. 11장에서는 AI 밖의 세계, 즉 비즈니스 현장에서 실제로 쓰이는 **자동화·지도·SMS·클라우드 인프라** 를 연결합니다. Zapier로 수백 개 SaaS와 무코드 자동화를 연결하고, Google Maps로 위치 기반 기능을 추가하며, Twilio로 SMS·전화 알림을 구현하고, 네이버 클라우드로 국내 인프라를 완성합니다.

## 11.1 Zapier — 수백 개 SaaS와 무코드 자동화 연결

### 1) Zapier와 러버블의 관계

**Zapier**는 7,000개 이상의 앱을 연결하는 자동화 플랫폼입니다. 러버블 앱과 Zapier를 연결하면 코드 한 줄 없이 슬랙 알림, 구글 시트 기록, HubSpot CRM 업데이트, 노션 페이지 생성 등 복잡한 업무 자동화를 구현할 수 있습니다.

러버블과 Zapier의 연결 방향은 두 가지입니다:

```
[방향 1] 러버블 앱 → Zapier → 외부 서비스
   예시: 새 사용자 가입 → Zapier → Slack "#신규가입" 채널에 알림

[방향 2] 외부 서비스 → Zapier → 러버블 앱
   예시: HubSpot에 리드 추가 → Zapier → Supabase leads 테이블 삽입
```

---

### 2) 러버블 → Zapier 웹훅 연동 (아웃바운드)

**Zapier 웹훅 설정:**

```
① Zapier 대시보드 → Create Zap
② Trigger: Webhooks by Zapier → Catch Hook
③ 생성된 웹훅 URL 복사
   예: https://hooks.zapier.com/hooks/catch/123456/abcdef/
④ Action: Slack → Send Channel Message (또는 원하는 앱)
⑤ Zap 활성화
```

**Supabase Edge Function으로 Zapier 웹훅 호출:**

```typescript
// supabase/functions/trigger-zapier/index.ts
// 러버블 앱 이벤트 발생 시 Zapier 웹훅으로 데이터 전송

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { event, data } = await req.json();

  // 이벤트 유형별 Zapier 웹훅 URL 분기
  const ZAPIER_WEBHOOKS: Record<string, string> = {
    new_user:       Deno.env.get('ZAPIER_NEW_USER_WEBHOOK') ?? '',
    new_order:      Deno.env.get('ZAPIER_NEW_ORDER_WEBHOOK') ?? '',
    payment_failed: Deno.env.get('ZAPIER_PAYMENT_FAILED_WEBHOOK') ?? '',
    contact_form:   Deno.env.get('ZAPIER_CONTACT_FORM_WEBHOOK') ?? '',
  };

  const webhookUrl = ZAPIER_WEBHOOKS[event];
  if (!webhookUrl) throw new Error(`알 수 없는 이벤트: ${event}`);

  // Zapier 웹훅 호출
  const response = await fetch(webhookUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      event,
      timestamp: new Date().toISOString(),
      ...data,
    }),
  });

  if (!response.ok) throw new Error(`Zapier 웹훅 호출 실패: ${response.status}`);

  return new Response(
    JSON.stringify({ success: true }),
    { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
  );
});
```

**프론트엔드에서 이벤트 트리거:**

### 3) Zapier → 러버블 앱 (인바운드 웹훅)

외부 서비스에서 러버블 앱으로 데이터를 보내는 경우, Supabase Edge Function을 웹훅 수신 엔드포인트로 사용합니다:

```typescript
// supabase/functions/zapier-inbound/index.ts
// Zapier에서 보내는 데이터를 수신하여 Supabase DB에 저장

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  // 웹훅 인증 (비밀 토큰으로 위조 방지)
  const authHeader = req.headers.get('X-Webhook-Secret');
  if (authHeader !== Deno.env.get('ZAPIER_INBOUND_SECRET')) {
    return new Response('인증 실패', { status: 401 });
  }

  const payload = await req.json();

  // Zapier에서 전달한 데이터 구조 파싱
  // (Zapier Action 설정 시 필드 매핑에 따라 다름)
  const { type, ...data } = payload;

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  switch (type) {
    case 'new_lead':
      await supabase.from('leads').insert({
        name: data.name,
        email: data.email,
        company: data.company,
        source: data.source || 'zapier',
        created_at: new Date().toISOString(),
      });
      break;

    case 'support_ticket':
      await supabase.from('tickets').insert({
        subject: data.subject,
        body: data.body,
        requester_email: data.email,
        status: 'open',
      });
      break;
  }

  return new Response(JSON.stringify({ received: true }));
});
```

## 11.2 Google Maps API — 위치 기반 기능 완전 구현

### 1) Google Maps API 활성화

```
① https://console.cloud.google.com → 새 프로젝트 생성
② API 및 서비스 → 라이브러리 → 다음 API 활성화:
   - Maps JavaScript API    (지도 표시)
   - Places API             (장소 검색·자동완성)
   - Geocoding API          (주소 ↔ 좌표 변환)
   - Distance Matrix API    (거리·시간 계산)
③ 사용자 인증 정보 → API 키 생성
④ API 키 제한 설정 (필수):
   - HTTP 리퍼러 제한: 앱 도메인만 허용
   - API 제한: 위 4개 API만 허용
⑤ 러버블 환경변수에 등록:
   VITE_GOOGLE_MAPS_API_KEY = AIza...
```

> ⚠️ **WARNING**
> 
> Google Maps API 키는 프론트엔드 코드에 노출될 수밖에 없으므로, 반드시 **HTTP 리퍼러 제한**을 설정하여 허용된 도메인에서만 사용할 수 있도록 제한하세요. 제한 없이 배포하면 타인이 키를 무단 사용하여 예상치 못한 과금이 발생할 수 있습니다. Google Cloud Console → 사용자 인증 정보 → API 키 → 키 제한 → HTTP 리퍼러에서 `https://yourdomain.com/*`을 등록합니다.

### 2) 지도 컴포넌트 구현 — `@vis.gl/react-google-maps`

러버블은 구글 지도 연동 시 최신 공식 React 라이브러리인 `@vis.gl/react-google-maps`를 자동으로 선택합니다. 이 라이브러리는 구글이 직접 관리하는 공식 React 래퍼입니다.

```typescript
// src/components/GoogleMap.tsx
// @vis.gl/react-google-maps v1 기준

import { APIProvider, Map, Marker, InfoWindow } from '@vis.gl/react-google-maps';
import { useState } from 'react';

interface Location {
  id: string;
  name: string;
  address: string;
  lat: number;
  lng: number;
  category?: string;
}

interface GoogleMapProps {
  locations: Location[];
  center?: { lat: number; lng: number };
  zoom?: number;
  onLocationSelect?: (location: Location) => void;
}

const GoogleMapComponent = ({
  locations,
  center = { lat: 37.5665, lng: 126.9780 },  // 서울 시청 기본
  zoom = 13,
  onLocationSelect,
}: GoogleMapProps) => {
  const [selectedLocation, setSelectedLocation] = useState<Location | null>(null);

  return (
    // APIProvider: Google Maps API 키 전역 주입
    <APIProvider apiKey={import.meta.env.VITE_GOOGLE_MAPS_API_KEY}>
      <Map
        defaultCenter={center}
        defaultZoom={zoom}
        gestureHandling="greedy"    // 모바일에서 단일 손가락 스크롤 허용
        disableDefaultUI={false}
        mapId="teamboard-map"       // Cloud Console에서 생성한 Map ID
        style={{ width: '100%', height: '400px', borderRadius: '12px' }}
      >
        {/* 위치 마커 */}
        {locations.map((loc) => (
          <Marker
            key={loc.id}
            position={{ lat: loc.lat, lng: loc.lng }}
            title={loc.name}
            onClick={() => {
              setSelectedLocation(loc);
              onLocationSelect?.(loc);
            }}
          />
        ))}

        {/* 선택된 위치의 정보창 */}
        {selectedLocation && (
          <InfoWindow
            position={{ lat: selectedLocation.lat, lng: selectedLocation.lng }}
            onCloseClick={() => setSelectedLocation(null)}
          >
            <div className="p-2 min-w-[150px]">
              <h3 className="font-semibold text-gray-900">{selectedLocation.name}</h3>
              <p className="text-sm text-gray-500 mt-1">{selectedLocation.address}</p>
              {selectedLocation.category && (
                <span className="text-xs bg-blue-100 text-blue-700 px-2 py-0.5 rounded-full mt-2 inline-block">
                  {selectedLocation.category}
                </span>
              )}
            </div>
          </InfoWindow>
        )}
      </Map>
    </APIProvider>
  );
};

export default GoogleMapComponent;
```

### 3) 주소 자동완성 (Places Autocomplete)

```typescript
// src/components/AddressAutocomplete.tsx
// Google Places API 주소 자동완성 — 한국어 우선

import { useMapsLibrary } from '@vis.gl/react-google-maps';
import { useEffect, useRef, useState } from 'react';
import { Input } from '@/components/ui/input';

interface AddressResult {
  formatted: string;        // 전체 주소
  lat: number;
  lng: number;
  placeId: string;
  components: {
    city?: string;          // 시/군/구
    district?: string;      // 동/읍/면
    streetNumber?: string;
  };
}

const AddressAutocomplete = ({
  onSelect,
  placeholder = '주소를 입력하세요',
  country = 'KR',           // 한국 주소 우선
}: {
  onSelect: (result: AddressResult) => void;
  placeholder?: string;
  country?: string;
}) => {
  const inputRef = useRef<HTMLInputElement>(null);
  const [inputValue, setInputValue] = useState('');

  // Places 라이브러리 로드
  const placesLib = useMapsLibrary('places');

  useEffect(() => {
    if (!placesLib || !inputRef.current) return;

    const autocomplete = new placesLib.Autocomplete(inputRef.current, {
      componentRestrictions: { country },   // 국가 제한 (KR = 한국)
      fields: ['formatted_address', 'geometry', 'place_id', 'address_components'],
      types: ['address'],
    });

    autocomplete.addListener('place_changed', () => {
      const place = autocomplete.getPlace();
      if (!place.geometry?.location) return;

      // 주소 구성요소 파싱
      const components: AddressResult['components'] = {};
      place.address_components?.forEach((comp) => {
        if (comp.types.includes('locality')) components.city = comp.long_name;
        if (comp.types.includes('sublocality_level_1')) components.district = comp.long_name;
        if (comp.types.includes('street_number')) components.streetNumber = comp.long_name;
      });

      const result: AddressResult = {
        formatted: place.formatted_address!,
        lat: place.geometry.location.lat(),
        lng: place.geometry.location.lng(),
        placeId: place.place_id!,
        components,
      };

      setInputValue(result.formatted);
      onSelect(result);
    });

    return () => placesLib.event.clearInstanceListeners(autocomplete);
  }, [placesLib, country, onSelect]);

  return (
    <Input
      ref={inputRef}
      value={inputValue}
      onChange={(e) => setInputValue(e.target.value)}
      placeholder={placeholder}
      className="w-full"
    />
  );
};
```

### 4) 주소 → 좌표 변환 (Geocoding) Edge Function

```typescript
// supabase/functions/geocode/index.ts
// 주소 텍스트 → 위도/경도 변환 (서버 측 처리 권장)

serve(async (req) => {
  const { address } = await req.json();

  // Google Geocoding API 호출
  const params = new URLSearchParams({
    address: encodeURIComponent(address),
    key: Deno.env.get('GOOGLE_MAPS_SERVER_KEY')!,  // 서버용 키 (IP 제한)
    language: 'ko',
    region: 'KR',
  });

  const response = await fetch(
    `https://maps.googleapis.com/maps/api/geocode/json?${params}`
  );
  const data = await response.json();

  if (data.status !== 'OK' || !data.results[0]) {
    throw new Error(`주소를 찾을 수 없습니다: ${address}`);
  }

  const result = data.results[0];
  const location = result.geometry.location;

  return new Response(
    JSON.stringify({
      lat: location.lat,
      lng: location.lng,
      formatted_address: result.formatted_address,
      place_id: result.place_id,
    }),
    { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
  );
});
```

### 5) 거리 계산 + 가장 가까운 매장 찾기

```typescript
// src/hooks/useNearestStore.ts
// Distance Matrix API로 가장 가까운 지점 찾기

interface Store {
  id: string;
  name: string;
  address: string;
  lat: number;
  lng: number;
}

export function useNearestStore(stores: Store[]) {
  const [nearestStore, setNearestStore] = useState<(Store & { distance: string; duration: string }) | null>(null);
  const [loading, setLoading] = useState(false);

  const findNearest = async () => {
    setLoading(true);
    try {
      // 사용자 현재 위치 획득
      const position = await new Promise<GeolocationPosition>((res, rej) =>
        navigator.geolocation.getCurrentPosition(res, rej)
      );

      const { latitude: userLat, longitude: userLng } = position.coords;
      const origins = `${userLat},${userLng}`;
      const destinations = stores.map((s) => `${s.lat},${s.lng}`).join('|');

      // Edge Function을 통한 Distance Matrix 호출
      const { data } = await supabase.functions.invoke('google-distance-matrix', {
        body: { origins, destinations },
      });

      // 가장 가까운 매장 선택 (시간 기준)
      const minIndex = data.durations.indexOf(Math.min(...data.durations));

      setNearestStore({
        ...stores[minIndex],
        distance: data.distances[minIndex],   // "2.3 km"
        duration: data.durations_text[minIndex], // "8분"
      });
    } finally {
      setLoading(false);
    }
  };

  return { nearestStore, loading, findNearest };
}
```

> 📝 **NOTE**
> 
> Google Maps API는 사용량 기반 과금입니다. 2025년 기준 주요 API 가격은 지도 표시($7/1,000회), 장소 자동완성($17/1,000회), 지오코딩($5/1,000회)이며, 매월 $200 무료 크레딧이 제공됩니다. 개발 단계에서는 거의 무료이지만, MAU가 수천 명을 넘어가면 비용이 발생하기 시작합니다. 가능한 경우 지오코딩 결과를 Supabase에 캐싱하여 중복 호출을 방지하세요.

## 11.3 Twilio — SMS·전화·카카오 알림톡 연동

### 1) Twilio 개요 및 국내 활용

**Twilio**는 SMS, 음성 전화, WhatsApp, 이메일을 API로 제공하는 통신 플랫폼입니다. 국내 서비스에서는 주로 **국제 SMS 인증**, **주문 확인 문자**, **긴급 알림** 등에 활용됩니다.

> 📝 **NOTE**
> 
> 국내 수신자에게 마케팅 SMS를 대량 발송하는 경우에는 Twilio 대신 **네이버 클라우드 SENS** 또는 **카카오 알림톡** API를 사용하는 것이 법적으로 안전하고 비용도 저렴합니다. Twilio는 주로 **해외 사용자 대상 SMS** 또는 **2FA(이중 인증)** 에 적합합니다.

---

### 2) Twilio 계정 설정

```
① https://twilio.com → 가입 (전화번호 인증 필요)
② Console → Account Info에서 복사:
   - Account SID: ACxxx...
   - Auth Token: 비밀 토큰
③ Phone Numbers → Manage → Buy a number
   - 국제 SMS 발송용 번호 구매 ($1~2/월)
④ Supabase Edge Function Secrets에 등록:
   TWILIO_ACCOUNT_SID = ACxxx...
   TWILIO_AUTH_TOKEN = [Auth Token]
   TWILIO_PHONE_NUMBER = +1234567890
```

// supabase/functions/send-sms/index.ts
// Twilio SMS API

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { to, message, type = 'notification' } = await req.json();

  // 전화번호 형식 검증 (E.164 형식 필수)
  const phoneRegex = /^\+[1-9]\d{1,14}$/;
  if (!phoneRegex.test(to)) {
    return new Response(
      JSON.stringify({ error: '올바른 전화번호 형식이 아닙니다. 예: +821012345678' }),
      { status: 400 }
    );
  }

  const accountSid = Deno.env.get('TWILIO_ACCOUNT_SID')!;
  const authToken = Deno.env.get('TWILIO_AUTH_TOKEN')!;

  // Basic Auth (Base64)
  const auth = btoa(`${accountSid}:${authToken}`);

  // Twilio Messages API 호출
  const formData = new URLSearchParams();
  formData.append('To', to);
  formData.append('From', Deno.env.get('TWILIO_PHONE_NUMBER')!);
  formData.append('Body', message);

  const response = await fetch(
    `https://api.twilio.com/2010-04-01/Accounts/${accountSid}/Messages.json`,
    {
      method: 'POST',
      headers: {
        'Authorization': `Basic ${auth}`,
        'Content-Type': 'application/x-www-form-urlencoded',
      },
      body: formData.toString(),
    }
  );

  const result = await response.json();

  if (!response.ok) {
    throw new Error(`Twilio SMS 오류: ${result.message}`);
  }

  // 발송 로그 기록
  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  await supabase.from('sms_logs').insert({
    to,
    message,
    type,
    twilio_sid: result.sid,
    status: result.status,
    sent_at: new Date().toISOString(),
  });

  return new Response(
    JSON.stringify({ success: true, sid: result.sid }),
    { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
  );
});

### 4) OTP(일회용 비밀번호) 인증 구현

SMS OTP는 Supabase Auth의 Phone Auth 기능으로 직접 구현할 수 있습니다. Supabase가 Twilio와 직접 연동되어 OTP 발송·검증을 자동 처리합니다:

```
Supabase 대시보드 → Authentication → Providers → Phone
→ Enable Phone Provider 활성화
→ SMS Provider: Twilio 선택
→ Account SID / Auth Token / From 번호 입력
→ Save
```

**프론트엔드 OTP 인증 흐름:**

```typescript
// src/hooks/usePhoneAuth.ts
// Supabase Phone Auth + Twilio OTP

export function usePhoneAuth() {
  const [step, setStep] = useState<'input' | 'verify'>('input');
  const [loading, setLoading] = useState(false);

  // 1단계: 전화번호 입력 → OTP 발송
  const sendOTP = async (phone: string) => {
    setLoading(true);
    try {
      const { error } = await supabase.auth.signInWithOtp({
        phone,  // E.164 형식: +821012345678
      });
      if (error) throw error;
      setStep('verify');
    } finally {
      setLoading(false);
    }
  };

  // 2단계: OTP 입력 → 인증 완료
  const verifyOTP = async (phone: string, token: string) => {
    setLoading(true);
    try {
      const { data, error } = await supabase.auth.verifyOtp({
        phone,
        token,
        type: 'sms',
      });
      if (error) throw error;
      return data;
    } finally {
      setLoading(false);
    }
  };

  return { step, loading, sendOTP, verifyOTP };
}
```

### 2) [한국어 특화] SENS — 카카오 알림톡 + SMS

**SENS(Simple & Easy Notification Service)** 는 네이버 클라우드의 메시지 발송 서비스입니다. SMS, MMS, 카카오 알림톡, 카카오 친구톡, 이메일을 단일 API로 발송할 수 있습니다.

**SENS 설정:**

```
① https://console.ncloud.com → SENS → 서비스 신청
② 프로젝트 생성 → 서비스 ID 확인
③ 발신 번호 등록 (본인 인증 필요)
④ 카카오 알림톡 사용 시:
   - 카카오 채널 개설 (카카오 비즈니스 채널 신청)
   - 알림톡 채널 연동
   - 메시지 템플릿 사전 등록·심사 (1~3 영업일)
⑤ API 인증키 확인:
   Access Key + Secret Key (NCP 포털 마이페이지)
```

**SENS SMS/알림톡 발송 Edge Function:**

```typescript
// supabase/functions/ncp-send-message/index.ts
// 네이버 클라우드 SENS API — SMS + 카카오 알림톡

import { createHmac } from 'https://deno.land/std@0.168.0/node/crypto.ts';

// NCP API 서명 생성 (HMAC-SHA256)
function makeSignature(
  method: string,
  url: string,
  timestamp: string,
  accessKey: string,
  secretKey: string
): string {
  const message = `${method} ${url}\n${timestamp}\n${accessKey}`;
  return createHmac('sha256', secretKey)
    .update(message)
    .digest('base64');
}

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders });

  const { type, to, content, templateCode, templateParams } = await req.json();

  const accessKey = Deno.env.get('NCP_ACCESS_KEY')!;
  const secretKey = Deno.env.get('NCP_SECRET_KEY')!;
  const serviceId = Deno.env.get('NCP_SENS_SERVICE_ID')!;
  const timestamp = Date.now().toString();

  let apiUrl: string;
  let body: object;

  if (type === 'sms') {
    // SMS 발송
    apiUrl = `/sms/v2/services/${serviceId}/messages`;
    body = {
      type: 'SMS',
      from: Deno.env.get('NCP_SENS_FROM_NUMBER')!,
      content,
      messages: [{ to }],
    };
  } else if (type === 'alimtalk') {
    // 카카오 알림톡 발송
    apiUrl = `/alimtalk/v2/services/${serviceId}/messages`;
    body = {
      plusFriendId: Deno.env.get('NCP_KAKAO_CHANNEL_ID')!,
      templateCode,          // 사전 등록된 템플릿 코드
      messages: [{
        to,
        content,
        buttons: templateParams?.buttons || [],
      }],
    };
  } else {
    throw new Error(`지원하지 않는 메시지 유형: ${type}`);
  }

  const signature = makeSignature('POST', apiUrl, timestamp, accessKey, secretKey);

  const response = await fetch(`https://sens.apigw.ntruss.com${apiUrl}`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-ncp-apigw-timestamp': timestamp,
      'x-ncp-iam-access-key': accessKey,
      'x-ncp-apigw-signature-v2': signature,
    },
    body: JSON.stringify(body),
  });

  const result = await response.json();

  if (!response.ok) {
    throw new Error(`SENS 오류: ${result.errorMessage}`);
  }

  return new Response(
    JSON.stringify({ success: true, requestId: result.requestId }),
    { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
  );
});
```

Google Maps 대신 **네이버 지도 API**를 사용하면 국내 도로·건물 데이터가 더 정확하고, 도로명 주소 검색도 더 자연스럽게 작동합니다.

// src/hooks/useNaverMaps.ts
// 네이버 지도 API 연동 (Dynamic Map v3)

export function useNaverMaps(containerId: string) {
  const mapRef = useRef<any>(null);

  useEffect(() => {
    // 네이버 지도 스크립트 동적 로드
    const script = document.createElement('script');
    script.src = `https://oapi.map.naver.com/openapi/v3/maps.js?ncpClientId=${import.meta.env.VITE_NCP_CLIENT_ID}&submodules=geocoder,panorama`;
    script.async = true;

    script.onload = () => {
      const { naver } = window as any;

      mapRef.current = new naver.maps.Map(containerId, {
        center: new naver.maps.LatLng(37.5665, 126.9780),  // 서울 시청
        zoom: 13,
        mapTypeControl: true,
        zoomControl: true,
        zoomControlOptions: {
          position: naver.maps.Position.TOP_RIGHT,
        },
      });
    };

    document.head.appendChild(script);
    return () => { document.head.removeChild(script); };
  }, [containerId]);

  // 주소 검색 (네이버 Geocoder)
  const searchAddress = (address: string): Promise<{ lat: number; lng: number }> =>
    new Promise((resolve, reject) => {
      const { naver } = window as any;
      naver.maps.Service.geocode({ query: address }, (status: any, response: any) => {
        if (status !== naver.maps.Service.Status.OK) {
          reject(new Error('주소를 찾을 수 없습니다.'));
          return;
        }
        const item = response.v2.addresses[0];
        resolve({ lat: parseFloat(item.y), lng: parseFloat(item.x) });
      });
    });

  return { mapRef, searchAddress };
}

## 11.5 통합 알림 시스템 — 채널 우선순위 설계

### 1) 멀티채널 알림 아키텍처

실제 서비스에서는 단일 채널이 아닌 **사용자 설정 + 상황에 따라 최적의 채널을 선택**하는 알림 시스템이 필요합니다:

```typescript
// src/lib/notifications.ts
// 멀티채널 알림 라우터

type NotificationChannel = 'email' | 'sms' | 'alimtalk' | 'push' | 'slack';

interface NotificationConfig {
  userId: string;
  event: string;
  data: Record<string, any>;
  priority: 'low' | 'normal' | 'high' | 'urgent';
}

// 이벤트별 채널 우선순위 정의
const CHANNEL_PRIORITY: Record<string, NotificationChannel[]> = {
  // 긴급 알림: SMS → 이메일 → 슬랙
  payment_failed:    ['sms', 'email', 'slack'],
  account_security:  ['sms', 'email'],

  // 일반 알림: 이메일 → 알림톡
  order_confirmed:   ['alimtalk', 'email'],
  subscription_renewed: ['email'],

  // 저우선순위: 이메일만
  weekly_report:     ['email'],
  tip_of_the_day:    ['email'],
};

export async function sendNotification(config: NotificationConfig) {
  const channels = CHANNEL_PRIORITY[config.event] || ['email'];

  // 사용자 알림 설정 조회
  const { data: userPrefs } = await supabase
    .from('notification_preferences')
    .select('*')
    .eq('user_id', config.userId)
    .single();

  // 채널 순서대로 발송 시도 (첫 번째 성공 시 중단 또는 전체 발송)
  for (const channel of channels) {
    // 사용자가 해당 채널을 비활성화했으면 스킵
    if (userPrefs && !userPrefs[`${channel}_enabled`]) continue;

    try {
      await dispatchToChannel(channel, config);
      // 긴급 알림이 아니면 첫 채널 성공 시 중단
      if (config.priority !== 'urgent') break;
    } catch (err) {
      console.error(`${channel} 발송 실패, 다음 채널로:`, err);
    }
  }
}

async function dispatchToChannel(
  channel: NotificationChannel,
  config: NotificationConfig
) {
  switch (channel) {
    case 'email':
      return supabase.functions.invoke('send-email', {
        body: { userId: config.userId, type: config.event, data: config.data },
      });
    case 'sms':
      return supabase.functions.invoke('ncp-send-message', {
        body: { type: 'sms', ...config.data },
      });
    case 'alimtalk':
      return supabase.functions.invoke('ncp-send-message', {
        body: { type: 'alimtalk', ...config.data },
      });
    case 'slack':
      return supabase.functions.invoke('trigger-zapier', {
        body: { event: config.event, data: config.data },
      });
  }
}
```

> **서드파티 통합의 핵심은 모든 것을 직접 만들지 않는 것입니다.**

> Zapier로 7,000개 SaaS와 연결하고, Google Maps 또는 네이버 Maps로 위치 기반 경험을 더하며, Twilio·SENS로 SMS/알림톡을 구현하면 수개월치 개발 작업을 수일로 단축할 수 있습니다. 국내 서비스라면 Google Maps와 Twilio 외에 네이버 클라우드 Maps·SENS·CLOVA를 병행하는 것이 비용·정확도·법적 준수 세 측면 모두에서 유리합니다. 모든 외부 서비스 호출은 반드시 Supabase Edge Function을 통해 서버 측에서 처리하고, API 키를 프론트엔드 코드에 절대 노출하지 마세요.
