# 부록. 확장 도메인 공공 API 서베이 (22)

> 공공 Open API 가이드북 — 0장에서 분리된 별도 파일
> 이 장은 1~13·21장처럼 파라미터 단위까지 깊게 다루는 "심화 챕터"는 아니지만, **각 항목을 개별적으로 실제 조사해서 확인한 기본 정보**로 구성했습니다. 확인하지 못한 항목은 그 사실을 숨기지 않고 명시합니다.
> 최초 작성 후 소방청·경찰청·교육(NEIS)·식품의약품안전처를 후속 조사로 추가 확인했습니다(5·6절). **2026년 9월 재점검으로 마지막 미확인 항목이던 국민건강보험공단(NHIS)까지 해소됐습니다** — 이제 이 부록에 확인 안 된 항목은 없습니다.

### 0) 연결 고리 (Bridge)

0장 3.2에 "미검증 후보 목록"으로만 걸어뒀던 항목들을, 실제로 하나씩 검색해 기본 사실을 확인한 결과입니다. 심화가 필요해지는 항목은 이후 별도 정식 챕터(1~13·21장과 같은 깊이)로 승격합니다.

## 1) 행정·조달

### 관세청 UNI-PASS
- 포털: https://unipass.customs.go.kr
- 인증: UNI-PASS 회원가입 → My메뉴 > 서비스관리 > OpenAPI 사용관리에서 **API별로 개별 인증키** 발급
- 규모: 총 54종 API 제공 확인(화물통관진행정보, 수출이행내역, 입항보고, HS부호, 관세율 등)
- 제약: **IP가 아닌 도메인명으로만 호출 가능**, TLS1.2 이상 필요. 화물통관진행정보는 입항 후 3년 이내 데이터만 조회 가능
- 비용: 무료

### 조달청 (나라장터)
- 접근 경로: 공공데이터포털(data.go.kr)에 개별 등재 — 입찰공고정보서비스, 낙찰정보서비스, 계약정보서비스, 사용자정보서비스 등 다수
- 인증: data.go.kr serviceKey (3장 공통 패턴)
- 비용: 무료, 개발계정 트래픽 1,000(운영계정은 증설 신청 가능)

## 2) 교통·공간·부동산

### 국가교통정보센터(ITS)
- 포털: https://www.its.go.kr/opendata
- 확인된 요청 파라미터(교통소통정보 API): `apiKey`(필수), `type`(all/ex/its — 전체/고속도로/국도), `routeNo`, `drcType`(all/up/down/start/end)
- 인증: 자체 인증키 신청

### TAGO(국가대중교통정보센터)
- 포털: https://www.tago.go.kr, data.go.kr을 통해 활용신청
- 제공: 버스 위치·정류소·노선·도착정보, 고속/시외버스 정보 등
- 인증: data.go.kr serviceKey

### 국토교통부 (부동산·공간정보)
- 접근 경로: data.go.kr 개별 등재 — 아파트 매매/전월세 실거래가, 건축HUB 건축물대장정보, 연속지적도, 지오코더 API 등
- 특이사항: 공공데이터포털 **전체 API 활용신청 누적 순위 상위권**에 실거래가·연속지적도·자동차종합정보 등이 반복 등장하는 것으로 확인(2026년 6월 기준 누적 통계) — 실무에서 매우 널리 쓰이는 축
- 인증: data.go.kr serviceKey

## 3) 환경·해양·농림·산림

### 환경(에어코리아)
- 제공: 한국환경공단_에어코리아_대기오염정보 — data.go.kr 등재, REST
- 활용신청 누적 최상위권 API 중 하나로 확인(여러 활용신청 순위 통계에 반복 등장)

### 해양수산부
- (구)바다누리 해양정보 서비스: **2026년 4월 1일 구버전 Open API 종료 확정**, 신규 바다누리 서비스로의 전환은 **2026년 6월 22일 기준 "사전안내" 단계**로 재확인됩니다(이 책 집필 시점에도 신규 시스템이 완전히 열리지 않았을 가능성이 있음).
- 국립수산과학원(nifs.go.kr): 자체 OPENAPI 목록 운영 — 어장환경관측자료, 위성해양영상정보, 해파리정보, 적조정보, 실시간어장정보 등 8종 이상, 자체 인증키 발급
- 해양교통안전정보시스템(MTIS) Open API(mtisopenapi.komsa.or.kr, 한국해양교통안전공단): **재점검으로 신규 확인**. 연안여객선 운항정보·해양사고 통계·해양안전지수·선박운항정보 4갈래를 REST로 제공, 2026년 1월에도 API 변경 공지가 있어 활발히 유지보수되는 것으로 보입니다. 바다누리가 관측·예측 데이터 중심이라면 MTIS는 교통안전 중심으로 성격이 다릅니다.
- > **WARNING**: 해양 도메인은 마침 이번 조사 시점에 시스템이 전환 중이라, 기존 API 엔드포인트를 그대로 쓰면 곧 끊길 수 있습니다. 실제 착수 시점에 신규 바다누리 서비스 공지를 먼저 확인하십시오.

### 농림축산식품부
- 포털: https://data.mafra.go.kr — 회원가입 시 **인증키 자동발급**(1인 1개), 오픈API 사용신청은 자동승인
- 농사로(nongsaro.go.kr): 농업기술정보 전용 별도 포털, 본인인증 후 OpenAPI 신청

### 산림청
- 접근 경로: data.go.kr 다수 등재(산림자원통계, 산정보서비스, 전통마을숲위치도, 국립수목원 생물정보관서비스 등) — 공통 패턴(`serviceKey`/`pageNo`/`numOfRows`/`resultCode`/`resultMsg`) 확인
- 자체 포털도 별도 운영: forest.go.kr에 "백두대간 OPEN API" 등 자체 URL(`api.forest.go.kr/openapi/service/...`) 확인
- 국립산림과학원(청정넷): 도시숲 미세먼지 측정데이터 등 별도 API 계열

## 4) 재난·안전

### 재난안전데이터공유플랫폼
- 포털: https://www.safetydata.go.kr
- 성격: 재난관리책임기관(행안부·경찰청·소방청·기상청 등)으로부터 수집·연계한 데이터를 오픈API(REST, JSON/XML)로 변환 제공
- 인증: 플랫폼 자체 회원가입 + 활용신청
- 실사용 사례 확인: "행정안전부_긴급재난문자", "경찰청_교통_돌발정보", "소방청_소방_긴급구조정보", "기상청_특보통보문" 등이 월간 다수 호출되는 것으로 공식 통계에 표시됨 — 즉 **소방청·경찰청의 일부 재난 관련 데이터는 각 기관 개별 포털이 아니라 이 통합 플랫폼을 통해서도 접근 가능**

> **NOTE**: 소방청·경찰청이 자체 개발자 포털을 별도로 운영하는지는 이번 조사에서 개별 확인하지 못했습니다. 재난·치안 관련 데이터가 필요하면 이 플랫폼을 먼저 확인하고, 부족하면 각 기관을 개별 조사하는 순서를 권장합니다.

### 소방청 (후속 조사로 확인)
- 접근 경로: data.go.kr 개별 등재 — "소방청_화재 현황 정보 서비스"(발화장소별·발화요인별·인명피해), REST/XML, 개발계정 트래픽 99,999로 확인
- 지자체 단위 소방 데이터도 별도 존재: 예) "강원특별자치도_강원소방 격자단위 동적 소방지수 정보"(유동인구·구급처·출동빈도 지수 등 KOTI-KATEC 격자좌표 기반)
- 재난안전데이터공유플랫폼(safetydata.go.kr)에서도 "소방청_소방_긴급구조정보"가 다수 호출되는 것으로 확인(4절 참고) — 즉 소방 데이터는 **data.go.kr / 재난안전플랫폼 두 경로 모두에서 접근 가능**

### 경찰청 (후속 조사로 확인)
- 접근 경로: data.go.kr — 교통사고정보(교통사망사고 위치정보, 보행자 무단횡단 사고 다발지역 등 7종+, 사고위험지역 정보 등)가 **국가중점데이터**로 지정되어 오픈API+파일데이터 양쪽으로 제공됨을 확인(약 23만 건 규모, 도로교통공단의 "링크별 도로위험도지수"와 세트로 개방)
- 재난안전데이터공유플랫폼에서도 "경찰청_교통_돌발정보"가 확인됨
- 생활안전지도(safemap.go.kr, 행정안전부): 별도 개발자센터를 운영하며 자체 인증키를 발급하는 것으로 확인 — 안전 관련 정보를 다룰 때 경찰청 데이터와 함께 고려할 만함

## 5) 문화·관광·교육

### 한국관광공사 TourAPI 4.0
- 접근 경로: data.go.kr에서 "한국관광공사" 검색 → 활용신청
- 엔드포인트 예: `https://apis.data.go.kr/B551011/KorService/...`(searchKeyword, locationBasedList, detailCommon/detailIntro/detailInfo/detailImage 등)
- 공통 파라미터: `serviceKey`, `_type`(json/xml), `MobileOS`, `MobileApp`, `numOfRows` 등
- 비고: 2015년 1월 이후 발급 인증키는 URL 인코딩 불필요. JSON 응답 필드명이 콘텐츠 타입마다 일관되지 않는다는 점(다수 개발자 문서에서 공통 지적)이 실무 함정으로 꼽힘

### 인접 문화 API (github 공개 카탈로그에서 존재 확인, 개별 조사는 안 함)
국립중앙박물관 e뮤지엄, 한국등산·트레킹지원센터 숲길 Open API, 한국문화정보원, KOPIS(공연예술통합전산망) — 전부 apiKey 인증 방식으로 알려져 있으나, 이번 조사에서 각 포털을 직접 열어보지는 못했습니다.

### 교육 (후속 조사로 확인)
- 나이스(NEIS) 교육정보개방포털: https://open.neis.go.kr — 학교 정보 등을 실시간 개방형 API로 제공한다고 공식 소개 확인. 교육부 산하 시스템
- 교육통계서비스(kess.kedi.re.kr)는 존재를 확인했으나, Open API 제공 여부까지는 이번 조사에서 확인하지 못했습니다 — NEIS와 역할이 겹치지 않는지 실사용 전 확인 권장

## 6) 특허·고용·보건의료·식품

### 특허청 계열 — KIPRIS Plus
- 포털: https://plus.kipris.or.kr (운영: 한국특허정보원, 소관: 지식재산처)
- 제공 범위: 11종(총괄공시정보, 특허·실용신안, 인용문헌, 영문초록, 이력정보, 검색지원정보, 등록정보, 심판정보, 해외특허, 기계번역정보, 분류정보) — Open API(REST/SOAP) + Bulk Data
- 무료 한도: **월 1,000회**(data.go.kr 경유). 그 이상이나 Bulk Data가 필요하면 plus.kipris.or.kr 직접 가입 필요
- 확인된 예: 특허·실용신안 공개/등록공보 REST API — 검색/서지정보/도면·전문 3종 기능

### 고용노동부 워크넷
- 접근 경로: data.go.kr에 "한국고용정보원_워크넷 채용정보" 등재 확인(LINK 유형)
- 세부 요청 파라미터는 이번 조사에서 개별 확인하지 못했습니다.

### 보건의료 — HIRA / NHIS
- 건강보험심사평가원(HIRA): 보건의료빅데이터개방시스템(opendata.hira.or.kr) — 공공데이터(데이터셋·오픈API), 의료빅데이터분석(빅데이터센터), 의료통계분석 3갈래로 운영. Open API 신청은 **공공데이터포털(data.go.kr) 경유**로 로그인 후 진행. 인증키 양도·공유 불가가 명시됨
- 국민건강보험공단(NHIS): **재점검으로 확인됨.** nhiss.nhis.or.kr 자체 페이지에 "Open API 신청" 메뉴가 있지만, 정작 "승인 및 인증키 발급은 공공데이터포털(data.go.kr)"이라고 명시되어 있습니다 — 즉 NHIS도 **별도 포털 인증 없이 3장의 표준 data.go.kr 게이트웨이(`apis.data.go.kr`)를 그대로 씁니다.** 실제 등재 사례로 "국민건강보험공단_검진기관별 정보제공"(`openapi1.nhis.or.kr/openapi/service/rest/...`), "국민건강보험공단_장기요양기관 시설별 상세조회 서비스"(`apis.data.go.kr/B550928/...`, 수정일 2026-03-18로 최근까지 유지보수 확인)가 있습니다. 오픈소스 프로젝트(`kpubdata`)에서도 "NHIS 관련 데이터는 기존 serviceKey를 재사용할 수 있고 별도 포털 인증이 불필요하다"는 동일한 패턴이 반복 확인됩니다.
- > **WARNING**: 두 기관 모두 "빅데이터센터"급 정밀 데이터(표본코호트 등)는 셀프서비스 Open API가 아니라 별도 심의(공공데이터 제공 심의위원회)를 거치는 것으로 확인됩니다. 기본 통계성 API와 정밀 코호트 데이터를 혼동하지 않아야 합니다.

### 식품의약품안전처 (후속 조사로 확인)
- 포털: https://www.foodsafetykorea.go.kr(식품안전나라) — **자체 Open API 시스템을 운영**하며, data.go.kr과 별도로 자체 인증키를 발급하는 것으로 확인
- 요청 URL 패턴(공식 확인, 경로 기반):
  ```
  http://openapi.foodsafetykorea.go.kr/api/{인증키}/{서비스명}/{요청파일타입}/{요청시작위치}/{요청종료위치}/
  ```
  10장(ECOS), 20장(서울 열린데이터광장)과 **같은 "경로에 값을 순서대로 나열"하는 스타일**입니다 — 이 가이드북에서 세 번째로 확인된 사례입니다.
- 제공 데이터 예: 건강기능식품 영양DB, 바코드연계제품정보, 인허가 업소 정보, 방사선조사식품 품목인정 정보 등
- 신청 절차: 식품안전나라 회원가입·로그인 → 원하는 서비스 선택 → 활용목적 상세 기재 → 이용신청. 요청주소에는 `keyID`(인증키), `serviceID`, `datatype`(XML/JSON), `startIdx`, `endIdx`를 채워 사용
- 인접 기관: 식품안전정보원(foodinfo.or.kr)도 "국내외 일일정보 API"라는 별도 Open API를 운영(자체 `apiKey` 발급, `bgnde`/`endde` 파라미터로 기간 조회) — 식약처 산하지만 별도 시스템이므로 혼동 주의

> **TIP**: 경로 기반 URL 스타일(ECOS·서울시·식약처)을 쓰는 기관들은 대체로 **오래전부터 운영해온 레거시 API**인 경향이 확인됩니다. 반대로 최근 등재된 API일수록 3장의 쿼리스트링 공통 패턴(`serviceKey`/`pageNo`/`numOfRows`)을 따르는 경우가 많습니다 — 절대적 규칙은 아니지만 새 기관 API를 조사할 때 짐작에 도움이 됩니다.

## 7) 미해결 항목 — 이번 재점검으로 전부 해소됨

최초 작성 시 남아있던 소방청·경찰청·교육(NEIS)·식품의약품안전처는 5·6절에서 확인을 마쳤고, 마지막까지 남아있던 **국민건강보험공단(NHIS)**도 이번 2026년 9월 재점검으로 확인 완료됐습니다(6절) — data.go.kr 표준 게이트웨이를 그대로 쓴다는 것이 결론입니다.

이 부록에서 새로 발견된, 앞으로 재확인이 필요할 수 있는 항목은 오히려 다음과 같습니다.

- 해양수산부 신규 바다누리 서비스 — 전환이 아직 진행 중이므로(3절) 완료 시점에 재확인 필요
- 이번에 새로 찾은 MTIS Open API(3절)는 아직 파라미터 단위까지는 조사하지 않은 "존재 확인" 수준입니다
