---

### 제1장. 소프트웨어 개발이란 무엇인가?

**한 줄 요약:** 개발이 무엇인지, 누가 할 수 있는지, 잘하는 사람은 어떤 사람인지 정의한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 1.1 | 개발이란 무엇인가? | 소프트웨어 개발의 사전적·실무적 정의. 코딩과 개발의 차이. |
| 1.2 | 전공자 vs 비전공자 | CS 전공자와 비전공자의 실질적 차이. 비전공자도 충분히 개발자가 될 수 있는 이유. |
| 1.3 | 개발 잘하는 사람이란? | 단순 코딩 능력이 아닌 문제 해결력·설계력·커뮤니케이션의 중요성. |

---

### 제2장. 소프트웨어의 종류

**한 줄 요약:** 우리가 쓰는 소프트웨어가 어떻게 분류되는지, 그 안에서 개발자 역할이 어떻게 나뉘는지 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 2.1 | 앱의 종류 | 웹(Web), 앱(Native App), 하이브리드(Hybrid)의 개념과 차이. |
| 2.2 | 프론트엔드 vs 백엔드 | 사용자가 보는 화면(프론트)과 서버·데이터 처리(백엔드)의 역할 구분. |
| 2.3 | 풀스택이란? | 프론트+백엔드를 모두 다루는 풀스택 개발자의 현실적 의미. |

---

### 제3장. 개발 언어 및 프레임워크

**한 줄 요약:** 수많은 프로그래밍 언어 중 어떤 것을 왜 선택해야 하는지, 프레임워크는 무엇인지 파악한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 3.1 | C언어와 C++ | 저수준 언어의 역사와 객체지향 프로그래밍(OOP)의 등장 배경. |
| 3.2 | 서버 언어: Python | Python이 20년 이상 살아남은 이유. 데이터/AI/웹 서버에서의 활용. |
| 3.3 | 프론트엔드 언어와 React | 웹 브라우저용 언어의 특성. React가 광범위하게 쓰이는 이유와 이벤트 처리 개념. |
| 3.4 | 모바일 앱 언어 | iOS(Swift), Android(Kotlin), 크로스 플랫폼(Flutter/React Native) 비교. |
| 3.5 | 언어 선택 기준 | 목적별 언어 선택 가이드. 프레임워크와 라이브러리의 차이. |

### 제4장. 개발자의 필수 지식

**한 줄 요약:** 언어를 넘어 모든 개발자가 알아야 할 핵심 개념들을 정리한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 4.1 | 자료구조(Data Structure) | 배열, 스택, 큐, 트리 등 데이터를 담는 그릇의 종류와 선택 기준. |
| 4.2 | 함수 / 객체 / 컴포넌트 / 프레임워크 | 코드를 재사용하는 방법의 발전 과정. |
| 4.3 | API와 OpenAPI | 시스템 간 통신의 약속(계약)으로서의 API. OpenAPI(Swagger) 명세 소개. |
| 4.4 | REST와 RESTful | 웹 API 설계 원칙. RESTful하게 만든다는 것의 의미. |
| 4.5 | 동기 vs 비동기 | 줄 서서 기다리기 vs 번호표 받고 기다리기 비유로 이해하는 동기/비동기. |
| 4.6 | Ajax / XML / JSON | 페이지 새로고침 없이 데이터를 주고받는 방법. 데이터 포맷 JSON vs XML 비교. |

### 제5장. 소프트웨어 공학

**한 줄 요약:** 좋은 소프트웨어를 만들기 위해 팀이 어떻게 협력하고 개발 프로세스를 관리하는지 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 5.1 | 애자일(Agile) | 폭포수 모델의 한계와 애자일의 등장. 스프린트, 회고, 백로그 개념. |
| 5.2 | CBD (컴포넌트 기반 개발) | 레고 블록처럼 조립하는 개발 방식. 재사용성과 유지보수성. |
| 5.3 | DevOps | 개발(Dev)과 운영(Ops)의 통합. 왜 DevOps 문화가 필요한가. |
| 5.4 | CI/CD | 코드 통합·배포 자동화 파이프라인. GitHub Actions 등 실무 도구 소개. |

---

### 제6장. 컴퓨터 구조 및 운영체제

**한 줄 요약:** 소프트웨어가 실제로 어떻게 하드웨어 위에서 동작하는지 내부 원리를 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 6.1 | 컴퓨터 내부 구조 | CPU, 디스크, 메모리의 역할과 관계. 데이터 흐름 시각화. |
| 6.2 | 메모리 계층 구조 | L1 캐시 → 주메모리(RAM) → 가상메모리 계층의 존재 이유와 속도 차이. |
| 6.3 | 커널(Kernel) | 운영체제의 핵심. 하드웨어와 소프트웨어 사이의 중재자 역할. |
| 6.4 | 프로그램 vs 프로세스 vs 프로세서 | 실행 전·실행 중·실행 주체의 차이. |
| 6.5 | 프로세스 vs 스레드 | 식당 주방 비유로 이해하는 멀티프로세스 vs 멀티스레드. |
| 6.6 | 멀티스레딩(Multithreading) | 병렬 처리의 장점과 동시성 문제(Race Condition) 주의사항. |

---

### 제7장. 데이터베이스

**한 줄 요약:** 데이터를 체계적으로 저장하고 꺼내는 방법, 그리고 어떤 데이터베이스를 언제 써야 하는지 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 7.1 | DBMS란? | 데이터베이스 관리 시스템의 정의. RDB의 테이블·행·열 구조. |
| 7.2 | 앱과 DB의 연동 구조 | 클라이언트 → 서버 → DB의 3계층 구조. ORM 개념 소개. |
| 7.3 | SQL 기초 | SELECT, INSERT, UPDATE, DELETE 핵심 쿼리 예제. |
| 7.4 | NoSQL | RDB로 해결 안 되는 상황. MongoDB, Redis 등 NoSQL 종류와 사용 시점. |

---

### 제8장. 네트워크 기술

**한 줄 요약:** 인터넷이 어떻게 동작하는지, 웹 서비스가 어떻게 데이터를 주고받는지 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 8.1 | 클라이언트/서버 통신 (C/S) | 요청-응답 모델의 기본 개념. |
| 8.2 | TCP/IP | 인터넷 통신의 근간. 패킷, IP 주소, 포트 개념. |
| 8.3 | HTTP | 웹 통신 프로토콜. 요청 메서드(GET/POST/PUT/DELETE)와 상태 코드. |
| 8.4 | 웹 서버 vs WAS | 정적 콘텐츠(Web Server)와 동적 처리(WAS)의 역할 구분. Nginx vs Tomcat. |
| 8.5 | 세션 / 쿠키 / JWT | 로그인 상태를 유지하는 세 가지 방법 비교. 보안 차이점. |
| 8.6 | 라우터 / 스위치 / 로드밸런서 | 네트워크 장비의 역할. 트래픽을 분산하는 로드밸런서의 필요성. |
| 8.7 | Synchronized vs Asynchronous | 네트워크 통신에서의 동기/비동기 패턴. |

---

### 제9장. 시스템 아키텍처

**한 줄 요약:** 규모 있는 서비스가 어떻게 설계되는지, 마이크로서비스가 왜 등장했는지 이해한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 9.1 | 설계(Architecture)의 중요성 | 집 짓기 비유. 설계 없이 개발하면 생기는 현실적 문제. |
| 9.2 | 스타벅스 비유로 보는 아키텍처 | 주문-제조-픽업 흐름으로 이해하는 시스템 설계 원칙. |
| 9.3 | 모놀리식 vs MSA | 하나의 거대한 서버(모놀리식)와 잘게 쪼갠 서버(MSA)의 장단점 비교. |
| 9.4 | 마이크로서비스(MSA) 실전 | MSA 도입 시 고려 사항. 서비스 간 통신(API Gateway, 메시지 큐). |

### 제10장. 클라우드, 빅데이터, AI

**한 줄 요약:** 현대 IT 서비스의 인프라가 어떻게 구성되는지, AI와 빅데이터가 어떻게 연결되는지 조망한다.

#### 담을 내용

| 절 | 소주제 | 설명 |
|----|--------|------|
| 10.1 | 클라우드 컴퓨팅이란? | 온프레미스 vs 클라우드. 왜 클라우드로 이동하는가. |
| 10.2 | IaaS / PaaS / SaaS | 서비스 제공 레벨 비교. AWS, GCP, Azure 예시. |
| 10.3 | 하이브리드 & 서버리스 | 온프레미스+클라우드 혼합 전략. 서버리스(Lambda) 개념. |
