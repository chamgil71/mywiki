# Chapter 04. 첫 보관소 만들기
> 폴더 구조 설계 · 노트 생성·이동·삭제 · 탭 조작

## 0) 연결 고리 (Bridge)

Chapter 03에서 인터페이스의 각 영역을 파악했습니다.  
이제 보관소 안에 폴더와 노트를 실제로 만들고 관리하는 방법을 익힙니다.  
이 챕터의 실습을 마치면 **나만의 첫 보관소 뼈대**가 완성됩니다. Part 2 이후 모든 실습은 이 보관소 위에서 계속 이어집니다.

---

## 1) 개념 정의 및 필요성

### 보관소(Vault)의 구조 원칙

옵시디언 보관소는 단순한 파일 폴더와 같지만, 몇 가지 특수한 요소가 있습니다.

| 요소 | 설명 | 주의사항 |
|---|---|---|
| `.obsidian/` | 설정 저장 숨김 폴더 | 삭제 시 모든 설정 초기화 |
| `.md` 파일 | 노트 본문 (마크다운) | 어떤 텍스트 편집기로도 열기 가능 |
| 일반 폴더 | 노트 분류용 | 깊이 3단계 이내 권장 |
| 비(非) md 파일 | 이미지·PDF 등 첨부 파일 | `assets/` 폴더에 모아두기 권장 |

### 폴더 구조 설계의 원칙

> **처음부터 완벽한 폴더 구조를 만들려 하지 마세요.**

옵시디언의 강점은 태그와 링크로 노트를 연결하는 것이지, 폴더 계층으로 정보를 분류하는 것이 아닙니다. 처음에는 최대한 단순하게 시작하고, 필요에 따라 점진적으로 구조를 추가하는 것이 권장 방식입니다.

**최소 시작 구조 (초보자 권장):**
```
my-vault/
├── 00-inbox/        ← 분류 전 임시 보관
├── 10-notes/        ← 정리된 노트
├── 20-projects/     ← 진행 중 프로젝트
├── 30-resources/    ← 참고 자료
├── 90-archive/      ← 완료·보관
└── assets/          ← 첨부 파일 (이미지 등)
```

> 📌 **NOTE:** 숫자 접두사(`00-`, `10-` 등)는 파일 탐색기에서 폴더 순서를 고정하기 위한 관례입니다. 반드시 따를 필요는 없으나, 폴더가 많아질수록 유용합니다.

## 2) 핵심 원리 및 구조

### 파일 작업 흐름

```mermaid
flowchart LR
    A[새 노트 생성\nCtrl/Cmd+N] --> B[제목 입력]
    B --> C[본문 작성]
    C --> D{분류 필요?}
    D -->|즉시| E[폴더로 이동\n드래그 또는 우클릭]
    D -->|나중에| F[inbox에 임시 보관]
    F -->|정기 정리| E
    E --> G[태그 또는 링크 추가\nPart 2에서 다룸]

    style A fill:#7C3AED,color:#fff
    style G fill:#059669,color:#fff
```

### 노트와 폴더 관리의 핵심 규칙

**노트 이름 짓기 원칙:**
- 나중에 검색할 때 찾기 쉬운 이름을 사용합니다
- 날짜 접두사는 일지 성격의 노트에만 사용합니다 (예: `2024-01-15 회의록`)
- 한글·영문 모두 사용 가능하며, 특수문자 중 `/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`는 파일명에 사용할 수 없습니다

## 3) 실습 예제

### 실습 4-1. 폴더 만들기

```
방법 A: 파일 탐색기에서 우클릭
  → 좌측 사이드바 파일 탐색기 영역 빈 곳 우클릭
  → [새 폴더] 선택
  → 폴더 이름 입력: "00-inbox"
  → Enter

방법 B: 명령 팔레트 사용
  → Ctrl/Cmd + P → "new folder" 검색
  → [파일: 새 폴더 만들기] 실행
```

**실습:** 아래 5개 폴더를 순서대로 생성하세요.
1. `00-inbox`
2. `10-notes`
3. `20-projects`
4. `30-resources`
5. `assets`

---

### 실습 4-2. 노트 만들기 4가지 방법

```
방법 1: 리본 아이콘
  → 리본의 📄 아이콘 클릭 → 새 노트 생성

방법 2: 단축키
  → Ctrl/Cmd + N → 새 노트 생성

방법 3: 특정 폴더 안에 생성
  → 파일 탐색기에서 폴더 우클릭 → [새 노트]
  → 해당 폴더 안에 노트 생성됨

방법 4: 링크로 자동 생성 (Part 2에서 다룸)
  → 노트 본문에 [[없는 노트 이름]] 입력
  → 클릭하면 자동으로 새 노트 생성
```

**실습:** `10-notes` 폴더 안에 아래 3개 노트를 생성하세요.
1. `나의 첫 번째 노트`
2. `오늘 배운 것`
3. `아이디어 메모`

---

### 실습 4-3. 노트 이동·이름 변경·삭제

```
이름 변경:
  → 파일 탐색기에서 노트 우클릭 → [이름 바꾸기]
  → 또는 노트 탭 더블클릭
  → 새 이름 입력 후 Enter
  ※ 이름 변경 시 이 노트를 참조하는 모든 링크가 자동 업데이트됩니다

이동:
  → 방법 A: 파일 탐색기에서 드래그 앤 드롭
  → 방법 B: 노트 우클릭 → [다른 폴더로 이동]
  → 방법 C: 명령 팔레트 → "move file" → [현재 파일 이동]

삭제:
  → 파일 탐색기에서 우클릭 → [삭제]
  → 또는 파일 선택 후 Delete 키
  ※ 기본 설정: 시스템 휴지통으로 이동 (복구 가능)
  ※ 설정에서 "옵시디언 휴지통"으로 변경 시 .trash 폴더에 보관
```

> ⚠️ **WARNING:** 옵시디언에서 노트 이름을 변경하면 해당 노트를 참조하는 모든 `[[링크]]`가 자동 업데이트됩니다. 단, 외부 앱(파일 탐색기, Finder)에서 파일 이름을 직접 변경하면 링크가 깨집니다. **반드시 옵시디언 내부에서 이름을 변경하세요.**

### 실습 4-4. 탭 조작 완전 정복

```
새 탭 열기:
  → Ctrl/Cmd + T 또는 탭 바의 [+] 버튼

탭 닫기:
  → Ctrl/Cmd + W 또는 탭 × 버튼

탭 간 이동:
  → Ctrl + Tab (다음 탭) / Ctrl + Shift + Tab (이전 탭)
  → 또는 탭을 직접 클릭

배경에서 탭 열기:
  → 파일 탐색기에서 Ctrl(Windows)/Cmd(Mac) + 클릭
  → 현재 탭은 유지하면서 백그라운드에 새 탭 열림

화면 분할:
  → 탭을 편집 영역 우측 끝으로 드래그
  → 좌우 분할 화면 생성
  → Ctrl/Cmd + P → "split" → 분할 관련 명령 모음
```

**실습:** 아래 워크플로우를 직접 수행해보세요.
```
① Ctrl/Cmd+N 으로 새 노트 생성 → 제목: "탭 연습 A"
② 다시 Ctrl/Cmd+N → "탭 연습 B" 생성
③ Ctrl+Tab 으로 A↔B 전환
④ "탭 연습 B" 탭을 오른쪽으로 드래그 → 화면 분할
⑤ 왼쪽에서 A 편집, 오른쪽에서 B 편집
⑥ Ctrl/Cmd+W 로 한쪽 탭 닫기
```

## 4) 실무 시나리오 (Best Practice)

### 폴더 구조 설계 시 자주 저지르는 실수

**실수 1: 너무 세분화된 폴더 구조로 시작**  
처음부터 `10-notes/프로그래밍/Python/기초/변수/` 처럼 5단계 폴더를 만드는 경우입니다. 나중에 구조를 바꾸기 어렵고, 노트를 어느 폴더에 넣어야 할지 결정 피로가 생깁니다.  
→ **해결:** 최대 2단계 이내로 시작. 태그와 링크로 세분화는 나중에.

**실수 2: 폴더 이름에 공백 사용**  
`My Notes`, `독서 노트`처럼 공백이 포함된 폴더명은 링크 문법에서 문제를 일으킬 수 있습니다.  
→ **해결:** `my-notes`, `독서노트` 처럼 하이픈이나 공백 없이 사용 권장.

**실무 사례 — 30분 보관소 구축:**
```
1분: 보관소 생성
5분: 기본 폴더 5개 생성 (00-inbox ~ assets)
10분: 현재 가지고 있는 중요 노트를 inbox에 옮기기
10분: inbox 노트를 적절한 폴더로 분류
4분: 첨부 폴더 경로 설정
```

## 5) 트러블슈팅 & 주의사항

### Q1. 파일 탐색기에서 노트 순서가 이상하게 정렬돼요

`설정 → 파일 및 링크 → 정렬 기준`에서 원하는 정렬 방식을 선택하세요. 파일 이름 기준 오름차순이 기본값입니다. 숫자 접두사(`01-`, `02-`)를 사용하면 순서를 고정할 수 있습니다.

### Q2. 실수로 노트를 삭제했어요

`설정 → 파일 및 링크 → 삭제된 파일 처리` 설정에 따라 다릅니다.
- **시스템 휴지통:** 운영체제 휴지통에서 복구
- **옵시디언 휴지통:** 보관소 내 `.trash` 폴더에서 복구
- **영구 삭제:** 복구 불가

> ⚠️ **WARNING:** 기본 설정을 "옵시디언 휴지통"으로 변경해두는 것을 강력 권장합니다. `설정 → 파일 및 링크 → 삭제된 파일 → 옵시디언 휴지통으로 이동`

### Q3. 폴더를 이동했더니 링크가 깨졌어요

옵시디언에서 폴더를 이동할 때 내부 노트 링크는 자동 업데이트되지 않는 경우가 있습니다. `설정 → 파일 및 링크 → 이동 시 링크 자동 업데이트` 를 **켜짐**으로 설정하세요.

## 6) 한 줄 요약

> 💡 **Key Takeaway:**  
> 보관소는 단순하게 시작하는 것이 정답이다. 폴더는 최대 2단계, 숫자 접두사로 순서 고정, 첨부 파일은 assets 폴더 지정. **지금 당장 완벽한 구조를 만들려 하지 말고, 이동·수정·삭제가 언제든 가능하다는 것을 기억하라.**
