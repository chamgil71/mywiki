# Chapter 08. 이미지·파일 첨부 관리
> 첨부 폴더 설정 · 이미지 삽입 · 크기 조절 · PDF 임베드 · 관리 전략

---

## 0) 연결 고리 (Bridge)

Chapter 07에서 노트와 노트를 링크로 연결하는 방법을 익혔습니다.  
이 챕터에서는 노트에 **이미지, PDF, 기타 파일을 첨부하고 관리하는 방법**을 다룹니다.  
첨부 파일 관리를 처음부터 올바르게 설정하지 않으면 보관소 안에 파일이 흩어져 나중에 정리가 어려워집니다.

---

## 1) 개념 정의 및 필요성

### 첨부 파일 관리의 핵심 원칙

옵시디언에서 이미지를 노트에 붙여넣으면 해당 파일이 보관소 어딘가에 복사됩니다. 기본 설정 그대로 두면 **노트가 있는 폴더에 이미지가 함께 저장**되어 폴더가 지저분해집니다.

**설정 전 (기본값):**
```
my-vault/
├── 10-notes/
│   ├── 회의록.md
│   ├── 스크린샷_2024-01-15.png   ← 노트 폴더에 섞임
│   └── 다이어그램.png
```

**설정 후 (권장):**
```
my-vault/
├── 10-notes/
│   └── 회의록.md
└── assets/
    ├── 스크린샷_2024-01-15.png   ← 한 곳에 모임
    └── 다이어그램.png
```

## 3) 실습 예제 및 실행 환경

### 실습 8-1. 첨부 파일 폴더 설정 (필수)

```
① 설정(⚙️) → 파일 및 링크
② "첨부 파일 기본 폴더" 항목 찾기
③ 드롭다운에서 "지정된 폴더" 선택
④ 폴더 경로에 "assets" 입력
⑤ 설정 창 닫기
```

> ⚠️ **WARNING:** 이 설정을 하지 않으면 모든 첨부 파일이 노트와 같은 폴더에 저장됩니다. **지금 바로 설정하세요.**

**세부 옵션 설명:**

| 옵션 | 동작 | 권장 여부 |
|---|---|---|
| 보관소 루트 폴더 | 모든 파일을 최상위에 저장 | ❌ |
| 현재 파일과 같은 폴더 | 노트 옆에 저장 (기본값) | ❌ |
| 지정된 폴더 | `assets/` 등 고정 폴더 | ✅ 권장 |
| 현재 파일 하위 폴더 | 노트별 폴더 자동 생성 | 선택 |

---

### 실습 8-2. 이미지 삽입 3가지 방법

**방법 1: 드래그 앤 드롭 (가장 쉬움)**
```
① 파일 탐색기(Finder/Explorer)에서 이미지 파일 선택
② 옵시디언 편집 영역으로 드래그
③ 자동으로 assets 폴더에 복사되고 링크 생성:
   ![[이미지파일명.png]]
```

**방법 2: 클립보드 붙여넣기**
```
① 스크린샷 캡처 (Windows: Win+Shift+S / Mac: Cmd+Shift+4)
② 옵시디언 편집 영역 클릭
③ Ctrl/Cmd + V 붙여넣기
④ 자동으로 저장 및 링크 생성:
   ![[Pasted image 20240115.png]]
```

> 💡 **TIP:** 스크린샷 붙여넣기는 옵시디언 가이드 작성에 필수적인 기능입니다. `Win+Shift+S` (Windows) 또는 `Cmd+Shift+4` (Mac)로 영역 캡처 후 바로 붙여넣기하면 됩니다.

**방법 3: `![[]]` 문법 직접 입력**
```markdown
<!-- 이미 assets 폴더에 있는 파일 참조 -->
![[이미지파일.png]]

<!-- 외부 URL 이미지 -->
![설명](https://example.com/image.png)
```

---

### 실습 8-3. 이미지 크기 조절

```markdown
<!-- 기본 (원본 크기) -->
![[이미지.png]]

<!-- 너비 지정 (px 단위) -->
![[이미지.png|300]]

<!-- 너비×높이 지정 -->
![[이미지.png|400x300]]

<!-- 가운데 정렬 + 크기 (HTML 사용) -->
<p align="center">
  <img src="이미지.png" width="400">
</p>
```

> 📌 **NOTE:** 이미지 크기 지정(`|300`)은 옵시디언 전용 문법입니다. 다른 마크다운 렌더러에서는 `|300` 이 텍스트로 표시될 수 있습니다. 이식성이 중요하다면 HTML `<img>` 태그를 사용하세요.

---

### 실습 8-4. PDF 및 기타 파일 임베드

```markdown
<!-- PDF 첫 페이지를 미리보기로 표시 -->
![[문서.pdf]]

<!-- PDF의 특정 페이지 -->
![[문서.pdf#page=3]]

<!-- 오디오 파일 (재생 플레이어 표시) -->
![[녹음.mp3]]

<!-- 비디오 파일 -->
![[영상.mp4]]
```

> ⚠️ **WARNING:** 대용량 파일(영상, 고해상도 이미지)을 보관소에 다수 포함하면 동기화 용량이 급증합니다. 대용량 파일은 외부 링크로 참조하거나, 별도 미디어 보관소를 만들어 관리하는 것을 권장합니다.

---

### 실습 8-5. 첨부 파일 관리 전략

**명명 규칙 설정:**
```
권장 파일명 형식:
YYYYMMDD-설명.확장자

예시:
20240115-회의록-화면캡처.png
20240115-프로젝트A-다이어그램.png
```

**orphan 파일 정리 (참조되지 않는 파일 찾기):**
```
Ctrl/Cmd + P → "orphan" 검색
→ [파일: 첨부 파일 중 사용되지 않는 파일 찾기]
→ 보관소에 있지만 어느 노트에서도 참조하지 않는 파일 목록 표시
→ 불필요한 파일 정리
```

## 4) 실무 시나리오 (Best Practice)

### 첨부 파일 폴더 구조 — 규모별 전략

**소규모 보관소 (노트 100개 미만):**
```
assets/   ← 모든 첨부 파일 한 폴더
```

**중규모 보관소 (노트 100~500개):**
```
assets/
├── images/   ← 이미지
├── pdfs/     ← PDF 문서
└── audio/    ← 녹음 파일
```

**대규모 보관소 (노트 500개 이상):**
```
assets/
├── 2024/     ← 연도별 폴더
│   ├── 01/   ← 월별 폴더
│   └── 02/
└── 2025/
```

> 💡 **TIP:** 설정에서 `현재 파일 하위 폴더` 옵션을 사용하면 `10-notes/회의록/`처럼 노트별 전용 폴더가 자동 생성됩니다. 첨부 파일이 많은 경우 이 방식도 유용합니다.

### 안티 패턴

- **이미지를 외부 URL로만 참조:** 해당 URL이 만료되면 이미지가 사라집니다. 중요한 이미지는 반드시 보관소에 복사하세요
- **모든 이미지를 원본 크기로 삽입:** 고해상도 이미지가 많으면 노트 스크롤이 느려집니다. `|600` 정도로 크기를 제한하세요

## 5) 트러블슈팅 & 주의사항

### Q1. 이미지가 표시되지 않고 `![[파일명.png]]` 텍스트로 표시됩니다

파일이 `assets/` 폴더에 실제로 존재하는지 확인하세요. 파일명에 한글이나 특수문자가 포함된 경우 인식이 안 될 수 있습니다. 파일명을 영문으로 변경하고 다시 링크를 업데이트하세요.

### Q2. 붙여넣기 이미지 파일명이 `Pasted image...` 로 저장됩니다

이것은 정상 동작입니다. 파일명이 자동으로 생성됩니다. 나중에 파일 탐색기에서 직접 이름을 변경하거나, `Paste Image Rename` 커뮤니티 플러그인을 사용하면 붙여넣기 시 이름을 지정할 수 있습니다.

### Q3. 이미지를 다른 폴더로 이동했더니 링크가 깨졌어요

옵시디언 내부의 파일 탐색기에서 이동해야 링크가 자동 업데이트됩니다. 운영체제의 파일 탐색기에서 직접 이동하면 링크가 깨집니다.

## 6) 한 줄 요약

> 💡 **Key Takeaway:**  
> 첨부 파일 관리의 핵심은 **처음부터 `assets/` 폴더를 지정하는 것**이다.  
> 설정 하나로 보관소의 파일 구조가 깔끔하게 유지된다.
