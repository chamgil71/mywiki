# Chapter 28. 30일 옵시디언 챌린지
> 습관 형성 · 단계별 미션 · 완료 체크리스트

---

## 0) 연결 고리 (Bridge)

1~27챕터를 통해 옵시디언의 모든 기능을 익혔습니다.  
이제 남은 것은 **지식이 습관으로 굳어지는 것**입니다.  
이 챕터는 30일 동안 매일 하나의 미션을 수행하며 옵시디언을 생활의 일부로 만드는 구조화된 챌린지입니다.

---

## 1) 챌린지 구조

### 30일 4주 커리큘럼

| 기간 | 주제 | 목표 |
|---|---|---|
| 1~7일 (Week 1) | 기초 습관 형성 | 매일 노트 작성 루틴 정착 |
| 8~14일 (Week 2) | 연결과 구조 | 링크와 PARA 시스템 완성 |
| 15~21일 (Week 3) | 자동화와 심화 | 템플릿·Dataview 일상화 |
| 22~30일 (Week 4+) | 나만의 시스템 | 모든 기능 통합·정착 |

---

## 2) Week 1: 기초 습관 형성 (Day 1~7)

### Day 1 — 첫 번째 데일리 노트
```
미션: 데일리 노트 템플릿으로 오늘의 첫 노트를 작성하세요.
  ① 데일리 노트 열기 (Ctrl/Cmd+P → "오늘의 노트")
  ② 오늘 목표 3가지 작성
  ③ 오늘 하루 중 배운 것 1가지 기록
소요시간: 5분
체크: - [ ] Day 1 완료
```

### Day 2 — 마크다운 6개 문법 연습
```
미션: 이 6개 문법을 노트에서 각각 1번씩 사용해보세요.
  ① # 헤딩  ② **굵게**  ③ - 리스트  
  ④ - [ ] 체크박스  ⑤ > 인용  ⑥ [[내부링크]]
소요시간: 10분
체크: - [ ] Day 2 완료
```

### Day 3 — 허브 노트 만들기
```
미션: 보관소의 진입점이 되는 "나의 두 번째 뇌.md" 허브 노트를 만드세요.
  ① 파일명: "나의 두 번째 뇌" 또는 "HOME"
  ② H1 제목: 나의 지식 관리 시스템
  ③ 섹션: 현재 프로젝트 / 학습 중 / 최근 노트
  ④ 다른 노트 3개 이상 [[링크]]
소요시간: 15분
체크: - [ ] Day 3 완료
```

### Day 4 — 태그 시스템 설계
```
미션: 내 보관소만의 태그 체계를 설계하고 기존 노트 5개에 적용하세요.
  ① status 계층 태그 설계 (진행중/완료/보류 등)
  ② type 계층 태그 설계 (회의록/독서노트/아이디어 등)
  ③ 기존 노트 5개에 태그 추가
소요시간: 15분
체크: - [ ] Day 4 완료
```

### Day 5 — 첫 번째 독서 노트
```
미션: 지금 읽고 있거나 최근에 읽은 책의 독서 노트를 Ch 13 템플릿으로 작성하세요.
  ① 독서 노트 속성 20종 중 최소 10개 채우기
  ② 핵심 주장 3가지 기록
  ③ 인상적인 구절 1개 + 나의 생각
소요시간: 20분
체크: - [ ] Day 5 완료
```

### Day 6 — 그래프 탐색
```
미션: 전체 그래프 뷰를 열고 보관소 지도를 탐색하세요.
  ① 그래프 뷰 열기 (Ctrl/Cmd+G)
  ② 색상 그룹 3개 설정
  ③ 가장 큰 노드(허브)와 고립 노드 찾기
  ④ 고립 노드 1개에 링크 추가
소요시간: 15분
체크: - [ ] Day 6 완료
```

### Day 7 — Week 1 리뷰
```
미션: 첫 주를 되돌아보는 주간 리뷰를 작성하세요.
  ① 주간 리뷰 템플릿 실행
  ② 이번 주 만든 노트 목록 Dataview로 확인
  ③ 다음 주 목표 3가지 설정
소요시간: 20분
체크: - [ ] Day 7 완료 / Week 1 완성! 🎉
```

## 3) Week 2: 연결과 구조 (Day 8~14)

### Day 8 — PARA 폴더 완성
```
미션: PARA 4계층 폴더 구조를 완성하고 기존 노트를 재배치하세요.
  ① 10-PROJECTS / 20-AREAS / 30-RESOURCES / 90-ARCHIVES / 00-INBOX
  ② 현재 보관소 노트를 PARA 기준으로 최소 10개 이동
  ③ 프로젝트 목록 허브 노트 완성
소요시간: 30분
체크: - [ ] Day 8 완료
```

### Day 9 — 회의록 템플릿 실전 사용
```
미션: 오늘 또는 최근 회의를 Templater 회의록 템플릿으로 기록하세요.
  ① 회의록 템플릿 실행
  ② 프로젝트명·참석자·안건 입력
  ③ 결정 사항을 체크박스로 작성
  ④ 관련 프로젝트 노트에 링크 추가
소요시간: 15분
체크: - [ ] Day 9 완료
```

### Day 10 — 캔버스 마인드맵
```
미션: 현재 진행 중인 프로젝트나 관심 주제를 캔버스로 마인드맵으로 그리세요.
  ① 새 캔버스 파일 생성
  ② 중심 주제 카드 + 가지 5개 이상
  ③ 기존 노트 2개 이상을 노트 카드로 임베드
  ④ 그룹 박스로 관련 카드 묶기
소요시간: 20분
체크: - [ ] Day 10 완료
```

### Day 11 — Dataview 대시보드 구축
```
미션: "나의 대시보드.md" 노트에 Dataview 쿼리 3개를 작성하세요.
  ① 최근 수정된 노트 10개 목록
  ② 현재 진행 중인 프로젝트 목록
  ③ 미완료 체크박스 할일 목록
소요시간: 20분
체크: - [ ] Day 11 완료
```

### Day 12 — 백링크 탐색
```
미션: 가장 많이 링크된 노트를 찾고, 그 노트를 기반으로 새 노트를 작성하세요.
  ① 그래프에서 가장 큰 노드 클릭
  ② 백링크 패널에서 연결된 노트 모두 확인
  ③ 백링크 목록에서 영감을 받아 새 노트 1개 작성
소요시간: 20분
체크: - [ ] Day 12 완료
```

### Day 13 — CSS 스니펫 적용
```
미션: 한국어 폰트 + 헤딩 색상 스니펫을 적용하고 차이를 비교하세요.
  ① korean-fonts.css 생성 및 활성화
  ② heading-style.css 생성 및 활성화
  ③ 전후 비교 스크린샷 촬영 (선택)
소요시간: 15분
체크: - [ ] Day 13 완료
```

### Day 14 — Week 2 리뷰
```
미션: 2주 주간 리뷰를 실행하고 보관소 현황을 수치로 기록하세요.
  ① 총 노트 수, 링크 수 기록
  ② 가장 잘 정착된 습관과 어려웠던 것 기록
  ③ Week 3 목표 설정
소요시간: 25분
체크: - [ ] Day 14 완료 / Week 2 완성! 🎉
```

## 4) Week 3: 자동화와 심화 (Day 15~21)

### Day 15 — GTD 시스템 가동
```
미션: GTD 다음 행동 목록에 실제 할일 10개를 컨텍스트 태그와 함께 입력하세요.
  ① 다음-행동.md 열기
  ② 컴퓨터/전화/외출/집 컨텍스트별 분류
  ③ GTD 대시보드에서 필터 확인
소요시간: 20분
체크: - [ ] Day 15 완료
```

### Day 16 — 제텔카스텐 영구 노트 3개
```
미션: 최근 읽은 자료에서 배운 개념을 자신의 말로 영구 노트 3개로 작성하세요.
  ① 각 노트: 하나의 개념만 (단일 책임 원칙)
  ② 자신의 언어로 완전한 문장으로 작성
  ③ 서로 관련된 개념끼리 [[링크]]
소요시간: 30분
체크: - [ ] Day 16 완료
```

### Day 17 — Excalidraw 다이어그램
```
미션: 이번 주 배운 개념이나 시스템을 Excalidraw로 시각화하세요.
  ① 새 Excalidraw 파일 생성
  ② 도형 5개 이상 + 화살표 + 텍스트
  ③ 완성된 다이어그램을 관련 노트에 임베드
소요시간: 25분
체크: - [ ] Day 17 완료
```

### Day 18 — 주간 리뷰 + 월간 리뷰 설계
```
미션: 주간 리뷰를 실행하고, 월간 리뷰 템플릿을 새로 만드세요.
  ① 주간 리뷰 실행 (주간 리뷰 템플릿)
  ② templates/월간-리뷰-template.md 새로 작성
  ③ 월간 리뷰 항목 설계 (분기 목표, 독서, 성과 등)
소요시간: 30분
체크: - [ ] Day 18 완료
```

### Day 19 — 동기화 검증
```
미션: 모바일과 데스크탑 간 동기화를 완전히 검증하세요.
  ① 데스크탑에서 "동기화 테스트" 노트 작성
  ② 모바일에서 확인
  ③ 모바일에서 내용 추가 → 데스크탑 확인
  ④ 충돌 없이 완료됐는지 확인
소요시간: 10분
체크: - [ ] Day 19 완료
```

### Day 20 — 허브 노트 고도화
```
미션: Day 3에 만든 허브 노트를 완전한 지식 지도로 발전시키세요.
  ① PARA 계층 링크 추가
  ② Dataview로 최근 노트 목록 자동 표시
  ③ 자주 쓰는 검색을 북마크하고 허브에 링크
소요시간: 25분
체크: - [ ] Day 20 완료
```

### Day 21 — Week 3 리뷰
```
미션: 3주 리뷰를 실행하고 보관소가 어떻게 성장했는지 기록하세요.
  ① 그래프 뷰 스크린샷 저장 (Day 1과 비교)
  ② 총 노트 수, 링크 수, 태그 수 기록
  ③ 가장 도움이 된 기능 Top 3 기록
소요시간: 25분
체크: - [ ] Day 21 완료 / Week 3 완성! 🎉
```

## 5) Week 4: 나만의 시스템 (Day 22~30)

### Day 22~28: 자유 미션 (7일)

이 7일은 자신의 필요에 맞게 아래 목록에서 선택하거나 나만의 미션을 만드세요.

```
선택 미션 목록:
  □ MCP 연동 설정 (Ch 24)
  □ Obsidian Publish 또는 Quartz로 사이트 발행 (Ch 27)
  □ 나만의 테마+CSS 스니펫 조합 완성 (Ch 23·25)
  □ 독서 노트 5권 작성 (Ch 20)
  □ Dataview 대시보드 고도화 (Ch 22)
  □ 제텔카스텐 노트 10개 영구 노트화 (Ch 21)
  □ 팀/가족과 보관소 공유 설정
  □ 연간 계획 캔버스 작성
  □ 기술 스택 또는 학습 로드맵 Excalidraw
  □ 나만의 미션: _______________
```

### Day 29 — 30일 결산 보고서
```
미션: "30일 챌린지 결산.md" 노트를 작성하세요.
  ① 30일 전 보관소 vs 지금 (노트 수, 링크 수, 구조 비교)
  ② 가장 잘 정착된 습관 3가지
  ③ 아직 어색한 부분과 개선 계획
  ④ 앞으로 3개월 목표
소요시간: 30분
체크: - [ ] Day 29 완료
```

### Day 30 — 시스템 문서화
```
미션: 내 보관소 사용 방법을 "시스템 안내서.md" 에 문서화하세요.
  내용:
  ① 폴더 구조 설명 (PARA 4계층)
  ② 태그 체계 설명
  ③ 일일/주간 루틴 설명
  ④ 주요 단축키 목록
  ⑤ 사용 중인 플러그인 목록
  
  → 6개월 후의 나 또는 새 팀원이 이 문서만 보면
    시스템을 이해할 수 있도록 작성
소요시간: 45분
체크: - [ ] Day 30 완료 🏆
```

## 7) 한 줄 요약

> **완벽하게 하지 않아도 된다. 매일 조금씩 쌓는 것이 가장 강력한 전략이다.**
