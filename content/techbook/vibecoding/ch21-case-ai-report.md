# 제21장. 사례 6 — AI 전략 보고서 자동화

> *"10번의 웹 검색, 출처 검증, 구조화 — AI가 혼자 해낸다."*

---

### 0) 연결 고리 (Bridge)

18장 레시피 1(문서 자동화) + 레시피 5(지식 베이스)의 결합 사례입니다. 이 사례는 AI 산업 동향, 정책 분석, 기업 전략 보고서처럼 **광범위한 정보 수집과 전문적 분석이 동시에 필요한 보고서**를 자동화한 실전 경험을 다룹니다. Magnificent 7 AI 전략 분석 보고서 작성 과정에서 만들어진 `ai-strategy-report SKILL.md v3.0`의 설계 원리와 실제 작동 방식을 공개합니다.

---

### 1) 문제 정의

#### 배경

AI 전략 보고서는 일반 문서 자동화와 다른 어려움이 있습니다.

```
AI 전략 보고서의 특수성:
  1. 정보가 빠르게 변함 (AI 분야는 월 단위로 변화)
  2. 1차 출처 확인 필수 (SEC 공시, 공식 발표 등)
  3. 수치·날짜 오류가 신뢰도에 치명적
  4. 다수 기업·정책을 동시에 비교하는 복잡한 구조
  5. 전문 독자와 비전문 독자를 동시에 만족해야 함

기존 수작업 방식의 문제:
  - 리서치: 4~8시간 (기사·논문·공시 검색)
  - 초안 작성: 3~4시간
  - 사실 검증: 2~3시간
  - 합계: 9~15시간/보고서

자동화 목표:
  - 리서치: Claude 웹 검색 10회 이상 자동화
  - 출처: Tier 1~3 신뢰도 분류 시스템
  - 사실 검증: AI가 수치와 날짜를 출처와 교차 검증
  - 결과: 1~2시간 내 검토 가능한 고품질 초안
```

### 2) ai-strategy-report SKILL.md v3.0 구조

```markdown
# AI 전략 보고서 작성 SKILL.md
버전: v3.0 | 업데이트: 2026-04-20

## 핵심 원칙
1. 모든 수치와 날짜는 반드시 1차 출처 확인
2. 10회 이상 검색으로 다각도 정보 수집
3. 출처 신뢰도 Tier 분류 필수 적용
4. Phase 1 완료 후 사용자 확인, Phase 2 진행

## 출처 신뢰도 Tier 시스템

### Tier 1 — 최고 신뢰도 (필수 우선 확인)
  - SEC 공시 (10-K, 10-Q, 8-K)
  - 기업 공식 투자자 발표 자료 (IR)
  - 정부 공식 문서 (관보, 예산서)
  - 학술 논문 (peer-reviewed)
  - 기업 공식 블로그·뉴스룸

### Tier 2 — 높은 신뢰도 (보조 확인)
  - 주요 언론 (로이터, AP, NYT, 조선일보, 한국경제)
  - 산업 분석 보고서 (가트너, IDC, 맥킨지)
  - 기관 연구 보고서 (KIST, ETRI, IITP)

### Tier 3 — 참고 수준 (단독 사용 지양)
  - 블로그, 개인 미디어
  - 집계 뉴스 사이트
  - SNS 발언

## Phase 1 — 리서치 단계

### 의무 검색 항목 (최소 10회)
  □ 주제 개요 검색 (2회)
  □ 주요 기업·기관별 최신 동향 (기업당 1회 이상)
  □ 정책·규제 동향 (1~2회)
  □ 시장 규모·전망 (1회, Tier 1 출처 우선)
  □ 경쟁사 비교 (1회)
  □ 최신 발표·이벤트 (1회)

### 수집 후 출처 목록 작성 형식
  > 출처 [Tier N]: 제목 (발행처, YYYY-MM-DD) — URL

### Phase 1 완료 보고 형식
  수집 완료. 총 N개 출처 (Tier 1: M개, Tier 2: K개, Tier 3: J개)
  주요 발견사항: [3~5가지]
  작성 진행할까요?

## Phase 2 — 보고서 작성 단계

### 구조 템플릿
  1. 요약 (Executive Summary) — 1페이지
  2. 시장 현황 — 수치 중심
  3. 주요 기업/기관 동향
  4. 정책 및 규제 환경
  5. 기술 트렌드
  6. 시사점 및 전망
  7. 출처 목록 (Tier별 분류)

### 수치 표기 원칙
  - 모든 수치에 출처 괄호 표기: (출처: SEC 10-K, 2025)
  - 불확실한 수치: "약", "추정" 명시
  - 상충되는 자료: 양쪽 수치 모두 제시

### 금지 사항
  - 출처 없는 수치·날짜 기재 금지
  - "~로 알려졌다" 등 불명확 표현 금지
  - Tier 3 단독 인용 금지
```

### 3) 실전 — Magnificent 7 AI 전략 보고서

실제 진행한 보고서 작성 세션의 전체 흐름을 공개합니다.

#### Phase 1 — 리서치 프롬프트

```
[ai-strategy-report SKILL.md v3.0 첨부]

Phase 1을 시작해줘.

주제: Magnificent 7(애플·마이크로소프트·알파벳·아마존·
     메타·엔비디아·테슬라)의 2025~2026년 AI 전략 분석

요청 범위:
  1. 각 기업의 AI 투자 규모 (공시 기준)
  2. 핵심 AI 제품·서비스 현황
  3. 대형 AI 모델 개발 현황 (자체 vs 외부 의존)
  4. AI 관련 M&A·파트너십
  5. 2025~2026 AI Capex 가이던스

수집 조건:
  - Tier 1 출처 우선 (SEC 10-K, 실적 발표)
  - 각 기업당 최소 1회 이상 검색
  - 총 10회 이상 검색
  - 상충되는 수치 발견 시 모두 기록
```

#### Phase 1 수행 결과 (실제 AI 출력 요약)

```
[AI 검색 실행 내역 — 총 14회]

검색 1: "Magnificent 7 AI investment 2025 annual report"

  → Google 10-K: $75B (2025 가이던스) ← 수치 확인

  → NVIDIA IR: 데이터센터 매출 $115.2B (FY2025)
  → 전년 대비 +93% ← Tier 1 확인

검색 3: "Apple AI strategy 2025 Apple Intelligence"
  → Apple Newsroom: Apple Intelligence 발표 (2024.06)
  → 자체 모델 + OpenAI 협력 구조 확인

검색 4: "Amazon AWS AI services 2025 earnings"
  → Amazon Q4 2024 실적 발표: AWS AI 가속화

검색 5: "Meta AI Llama 3 strategy open source"
  → Meta IR: Llama 3 오픈소스 전략 공식화
  → AI Capex $60~65B (2025 가이던스)

[이하 검색 6~14 생략]

━━━ Phase 1 완료 보고 ━━━
총 수집 출처: 23개
  Tier 1: 14개 (SEC 10-K 7개, 공식 IR 5개, 공식 블로그 2개)
  Tier 2: 7개 (주요 언론 5개, 산업 보고서 2개)

주요 발견사항:
  1. AI Capex 격차: 엔비디아 수혜 vs 나머지 투자 주체

  4. 애플: 에지 AI 전략 차별화 (서버 의존 최소화)
  5. 상충 수치: Amazon AI Capex — 언론 $100B vs 공시 미공개

Phase 2 진행할까요?
```

### 4) 사실 검증 오류 수정 사례

이 보고서 작성 과정에서 AI가 틀린 사실을 제시한 실제 사례입니다.

```
[오류 발생 — AI 초안]
"테슬라는 2025년 자체 LLM 'Grok'을 출시하여..."

[사용자 검토]
"Grok은 테슬라가 아니라 xAI(일론 머스크의 별도 회사)야."

[AI 수정]
"확인했습니다. Grok은 xAI의 제품입니다.
 테슬라와 xAI는 별개 회사이며, 일론 머스크가
 양사에 관여하고 있어 혼동이 발생했습니다.
 테슬라의 AI는 자율주행(FSD)과 Dojo 슈퍼컴퓨터에
 집중되어 있습니다. 수정하겠습니다."
```

이 사례가 보여주는 것: AI 생성 보고서에서 **인물·회사 관계, 제품 귀속, 날짜**는 반드시 사람이 검토해야 합니다.

### 5) SKILL.md 버전 발전 과정

```
v1.0 — 기본 검색 지시
  "10번 이상 검색해서 보고서 써줘"
  문제: 검색 수는 많아도 Tier 1 출처 없음

v2.0 — 출처 분류 도입
  Tier 1/2/3 분류 추가
  문제: Phase 구분 없어서 검증 전 작성 시작

v2.5 — Phase 분리
  Phase 1(리서치) → 사용자 확인 → Phase 2(작성)
  문제: 수치 오류 여전히 발생 (출처 명시 없음)

v3.0 — 수치 출처 필수화
  모든 수치에 (출처: 기관, 연도) 필수 표기
  상충 수치 발견 시 양쪽 모두 제시
  결과: 수치 오류율 대폭 감소, 독자 신뢰도 향상
```

### 6) 자동화 파이프라인 연결

```
[n8n 자동 발행 시스템]

트리거: Notion "보고서 요청" DB에 새 항목 생성 시

  (주제, 독자, 분량, 마감일)

  ai-strategy-report SKILL.md 시스템 프롬프트 적용
  웹 검색 도구 활성화
  → 리서치 결과 JSON 반환

노드 3: Notion 업데이트
  "Phase 1 완료 — 검토 요청" 상태 변경
  리서치 결과를 Notion 페이지에 저장

노드 4: Slack 알림
  "📊 보고서 Phase 1 완료
   주제: {{$json.topic}}
   [Notion에서 검토]"

[사용자 승인 후]

노드 5: Webhook 수신 (승인 버튼)

노드 6: Claude API (Phase 2)
  Phase 1 결과 + Phase 2 지시

노드 7: 보고서 파일 생성
  → HWPX 또는 MD 파일

노드 8: Notion + Slack 배포
  완성 보고서 업로드 + 팀 알림
```

```
  v1.0 시절: 오류 5~8건/보고서

  SKILL.md 하나로 매번 동일한 품질 재현
```

### 9) 한 줄 요약

> 💡 **Key Takeaway:** AI 전략 보고서 자동화의 핵심은 **Phase 분리(리서치→확인→작성), Tier 출처 분류, 수치 출처 필수 표기**이며, SKILL.md를 버전 관리하면서 오류에서 배운 규칙을 누적하면 보고서 품질이 지속적으로 향상됩니다.
