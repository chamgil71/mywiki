# 개인정보처리방침

**MS Wiki** (이하 "사이트")는 개인 지식 노트를 공유하는 정적 웹사이트입니다.  
운영자: chamgil@gmail.com  
사이트 주소: https://mywiki-khaki.vercel.app

---

## 1. 수집하는 정보

본 사이트 운영자는 방문자의 개인정보를 직접 수집하지 않습니다.  
단, 아래 외부 서비스가 각 서비스 정책에 따라 데이터를 처리합니다.

---

## 2. 외부 서비스

### Google AdSense (광고)

본 사이트는 Google AdSense를 통해 광고를 표시합니다.

- Google은 쿠키를 사용하여 방문자의 관심사 기반 광고를 제공할 수 있습니다.
- 개인 맞춤 광고 설정 변경: [Google 광고 설정](https://adssettings.google.com/)
- Google 개인정보처리방침: https://policies.google.com/privacy

### Plausible Analytics (방문 통계)

- 쿠키를 사용하지 않는 개인정보 친화적 분석 도구입니다.
- IP 주소, 기기 핑거프린트 등 개인 식별 정보를 수집하지 않습니다.
- 집계된 방문 통계(페이지뷰, 유입 경로 등)만 처리됩니다.
- Plausible 개인정보처리방침: https://plausible.io/privacy

### Giscus (댓글)

- GitHub Discussions 기반 댓글 서비스입니다.
- 댓글 작성 시 GitHub OAuth 로그인이 필요하며, GitHub 개인정보처리방침이 적용됩니다.
- GitHub 개인정보처리방침: https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement
- 댓글을 작성하지 않으면 어떠한 정보도 Giscus에 전달되지 않습니다.

---

## 3. 쿠키

본 사이트 자체는 쿠키를 설정하지 않습니다.  
Google AdSense에 의해 광고 목적의 쿠키가 브라우저에 저장될 수 있으며,  
브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있습니다.

---

## 4. 이용자 권리

- 광고 쿠키 거부: 브라우저 설정 → 쿠키 차단 또는 [Google 광고 설정](https://adssettings.google.com/)
- Giscus 댓글 데이터 삭제: GitHub Discussions에서 직접 삭제 가능
