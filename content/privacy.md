# 개인정보처리방침

**MS Wiki** (이하 "사이트")는 개인 지식 노트를 공유하는 정적 웹사이트입니다.  
운영자: chamgil@gmail.com  
사이트 주소: https://mywiki-khaki.vercel.app (미러: https://chamgil71.github.io/mywiki/)

---

## 1. 수집하는 정보

사이트 운영자는 방문자의 개인정보를 직접 수집하거나 저장하지 않습니다.  
회원가입, 문의 양식, 광고, 방문 통계 도구를 운영하지 않습니다.  
다만 사이트를 제공하는 과정에서 아래 외부 서비스가 각 서비스의 정책에 따라 데이터를 처리합니다.

---

## 2. 외부 서비스

### 호스팅 (Vercel, GitHub Pages)

- 사이트는 Vercel과 GitHub Pages에서 제공됩니다.
- 서비스 제공과 보안을 위해 호스팅 업체가 접속 기록(IP 주소, 요청 시각, 브라우저 정보 등)을 처리할 수 있습니다.
- Vercel 개인정보처리방침: https://vercel.com/legal/privacy-policy
- GitHub 개인정보처리방침: https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement

### Google Fonts (글꼴)

- 페이지 글꼴을 Google Fonts에서 불러오며, 이 과정에서 Google 서버에 IP 주소 등이 전달됩니다.
- Google 개인정보처리방침: https://policies.google.com/privacy

### Giscus (댓글)

- GitHub Discussions 기반 댓글 서비스입니다.
- 댓글 영역을 표시하기 위해 giscus.app과 GitHub에서 데이터를 불러오며, 이 과정에서 IP 주소 등이 해당 서비스에 전달됩니다.
- 댓글이나 반응을 남기려면 GitHub 로그인이 필요하며, 작성한 내용과 GitHub 계정 정보는 GitHub Discussions에 공개적으로 저장됩니다.
- GitHub 개인정보처리방침: https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement

---

## 3. 쿠키 및 브라우저 저장소

사이트 자체는 추적용 쿠키를 설정하지 않습니다.  
화면 테마(라이트/다크) 등 표시 설정은 브라우저의 로컬 저장소에만 보관되며 외부로 전송되지 않습니다.  
Giscus에 GitHub로 로그인하면 Giscus/GitHub의 인증 정보가 브라우저에 저장될 수 있으며, 브라우저 설정에서 삭제할 수 있습니다.

---

## 4. 이용자 권리

- 댓글 수정·삭제: GitHub Discussions에서 직접 수정하거나 삭제할 수 있습니다.
- Giscus 연동 해제: GitHub 설정 → Applications에서 Giscus 권한을 철회할 수 있습니다.
