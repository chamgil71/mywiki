* * *

 **① 기본지침 → ② 개별 스킬 → ③ 전체 워크플로우 스킬**의 3단 구조로 정리해준다.  

* * *

① 기본지침 (Global Instruction / Base Skill)
========================================

이건 모든 스킬이 공유하는 **헌법**이다.  
절대 특정 기술에 종속되지 않게 설계한다.

```md
# [BASE] AI System Core Guideline

## 역할
- 사용자의 요구를 "기획 → 구조화 → 실행 → 검증" 단계로 분해한다
- 각 단계는 반드시 독립된 스킬 호출로 수행한다
- 단일 스킬이 여러 책임을 갖지 않도록 한다 (SRP 원칙)

## 원칙
1. 상태는 저장소(Storage) 없이는 유지하지 않는다
2. 데이터는 Database 스킬을 통해서만 접근한다
3. 외부 연동은 Services 스킬을 통해서만 수행한다
4. 사용자 UI는 Web 스킬(Streamlit)로만 노출한다

## 출력 규칙
- 모든 중간 결과는 구조화(JSON/Dict)되어야 한다
- 재현 가능한 실행 순서를 항상 명시한다
```

* * *

② 개별 스킬 정의 (등록용 단위 스킬)
======================

아래 스킬들은 **각각 단독 등록 가능**해야 하고,  
워크플로우에서는 조립 부품처럼 사용된다.

* * *

🧠 Skill 1. Planner (기획/분해)
---------------------------

```md
# [SKILL] Task Planner

## 입력
- 사용자 요청 (자연어)

## 기능
- 목표 정의
- 하위 작업 분해
- 필요한 스킬 목록 추출
- 실행 순서 정의

## 출력
{
  "goal": "...",
  "tasks": [
    {"step": 1, "skill": "Storage"},
    {"step": 2, "skill": "Database"},
    {"step": 3, "skill": "Service"},
    {"step": 4, "skill": "Web"}
  ]
}
```

* * *

💾 Skill 2. Storage (Output / Artifact 저장)
------------------------------------------

```md
# [SKILL] Storage Manager

## 역할
- 중간 결과 및 최종 결과 저장
- 파일 / 로그 / 결과물 관리

## 지원 타입
- JSON
- CSV
- Markdown
- Binary (모델 결과)

## 예시 출력
{
  "storage_id": "result_2026_02_12.json",
  "path": "/outputs/"
}
```

* * *

🗄️ Skill 3. Database (데이터 관리)
------------------------------

```md
# [SKILL] Database Operator

## 역할
- 정형 데이터 CRUD
- 버전 관리
- 이력 추적

## 대상
- SQLite / Postgres / Vector DB
- 로컬 or 서버 DB

## 예시 출력
{
  "query": "SELECT * FROM logs",
  "rows": 128
}
```

* * *

🔌 Skill 4. Services (외부 연동)
----------------------------

```md
# [SKILL] External Services Connector

## 역할
- API 호출
- 인증 관리
- Webhook 처리

## 대상
- Telegram
- GitHub
- Notion
- LLM API
- 사내 API

## 예시 출력
{
  "service": "telegram",
  "status": "sent",
  "message_id": 12345
}
```

* * *

🌐 Skill 5. Web (Streamlit UI)
------------------------------

```md
# [SKILL] Web Interface (Streamlit)

## 역할
- 사용자 입력 UI
- 결과 시각화
- 상태 모니터링

## 기능
- Form
- Table
- Chart
- File Upload/Download

## 출력
{
  "ui": "streamlit",
  "page": "dashboard",
  "components": ["form", "table", "chart"]
}
```

③ 전체 워크플로우 스킬 (Orchestrator)
============================

이건 **“모든 걸 하는 슈퍼 스킬”이 아니라**  
**스킬을 호출만 하는 지휘자**다.

```md
# [WORKFLOW SKILL] Full AI Workflow Orchestrator

## 실행 순서
1. Planner 호출 → 작업 분해
2. Database → 기존 데이터 조회
3. Services → 외부 데이터 수집
4. Storage → 중간 결과 저장
5. Web → 사용자에게 결과 표시
6. Storage → 최종 결과 보관

## 특징
- 각 스킬 실패 시 롤백 가능
- 스킬 교체 가능 (DB → VectorDB 등)
- UI 없는 Headless 실행 가능
```

* * *

🧩 구조 요약 (한 줄로 정리)
------------------

> **Planner는 생각하고,  
> Storage는 기억하고,  
> Database는 질서 잡고,  
> Services는 바깥과 대화하고,  
> Web은 인간과 소통하고,  
> Workflow는 흐름을 만든다.**
