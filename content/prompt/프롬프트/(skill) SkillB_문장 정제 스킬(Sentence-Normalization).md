## 1. 스킬 목적 (Mission)

> 자유 형식으로 작성된 한국어 문서를  
> **공식 문서 규칙에 맞는 구조적·기계 처리 가능한 텍스트**로 변환한다.

이 스킬은 **글을 잘 쓰는 스킬이 아니다.**  
글을 **규칙에 맞게 "정제·분해·강제"하는 스킬**이다.

---

## 2. 스킬의 위치 (Pipeline 상 역할)

```
[Skill A] 초안 작성 (보고서작성, 시장 조사 등)
   ↓
[Skill B] 문장 정제 (본 스킬)
   ↓
[Skill C] HWPX 문서 생성·렌더링 스킬(hwpx-renderer)
```

|항목|Skill A|Skill B|Skill C|
|---|---|---|---|
|내용 생성|○|✕|✕|
|문체 규칙|✕|**◎**|✕|
|구조 분해|△|**◎**|✕|
|폰트·레이아웃|✕|✕|◎|

---

## 3. 입력 / 출력 명세

### 3.1 입력(Input)

```
input:
  text: string            # 자유 서술 원문
  options:
    target_style: report  # 기본값
    max_depth: 3          # □ ○ ―
    preserve_quotes: true
```

- 입력은 **문단 단위 텍스트**
- 이미 불릿(□ ○ ―)이 있더라도 **규칙 검증 후 재정렬**

---

### 3.2 출력(Output)

```
output:
  blocks:
    - level: headline     # □
      text: string
      char_count: int
    - level: body_1       # ○  ← (키워드) 접두 + **핵심맥락** 볼드 적용
      keyword: string     # ★ 신규: 해당 ○ 블록의 핵심 주제어 (괄호 없이 저장)
      text: string        # ★ 형식: (키워드) 문장 본문 **핵심수치·맥락** 나머지
      char_count: int
    - level: body_2       # ―
      text: string
      char_count: int
    - level: source       # *
      text: string
```

#### ○ 블록 출력 형식 예시

```
○ (시장규모) 2025년 기준 글로벌 피지컬 AI 시장 규모는 **약 50억 2,120만 달러~52억 3,000만 달러 수준**으로 추산됨.
○ (성장률) 연평균 성장률(CAGR) **32.5%~34.6%**로 팽창하여 2033~2035년에는 **497억~836억 달러** 규모 형성이 전망됨.
○ (지역별 점유) 북미가 **40.6%**로 시장을 주도하며, 아시아-태평양이 CAGR **34.6%**로 가장 빠른 성장세를 기록 중임.
```

⚠️ 출력은 **HWPX 비의존 순수 구조 텍스트**

---

## 4. 핵심 규칙 정의 (Rule Engine)

### 4.1 문장 길이 규칙

|레벨|기호|글자 수|
|---|---|---|
|headline|□|20~30|
|body_1|○|80~200|
|body_2|―|80~200|
|source|*|제한 없음|

#### 처리 정책

- 초과 → **분해**
- 미달 → **유지 (병합 금지)**

---

### 4.2 명사형 종결 규칙 (강제)

#### 허용 종결 목록 (화이트리스트)

```
임 / 함 / 됨 / 필요 / 중요 / 확대 / 강화 / 추진 / 제한 / 관리
```

#### 자동 변환 규칙 예시

|원문|변환|
|---|---|
|~이다|~임|
|~한다|~함|
|~되었다|~됨|
|~필요하다|~필요|
|~중요하다|~중요|

#### 변환 제외 조건

- 물음표 포함 문장
- 인용부호(" ", 「 」) 내부
- 법령·원문 인용

---

### 4.3 장문 분해 규칙 (핵심 기능)

#### 트리거

- 문장 길이 ≥ 120자

#### 분해 우선순위

1. **접속 부사**
    - 또한 / 한편 / 특히 / 다만 / 그러나 / 이에 따라
2. **의미 전환 조사**
    - ~하며 / ~하지만 / ~으로써
3. **결과·원인 분리**
    - 원인 → ○
    - 결과·조건 → ―

---

### 4.4 구조 재배치 규칙

```
1. 문단 요지 추출 → □
2. 설명 문장 → ○
3. 보충 / 조건 / 예외 → ―
```

- □는 **항상 하나**
- ○는 1~N
- ―는 ○ 하위에서만 생성

---

### 4.5 ○ 키워드 태그 규칙 ★ 신규

모든 ○ 블록의 **문장 맨 앞**에 `(키워드)` 를 붙인다.

#### 키워드 추출 원칙

|우선순위|방법|예시|
|---|---|---|
|1순위|문장의 **주어·주제** 추출|"시장 규모는..." → `(시장규모)`|
|2순위|문장의 **핵심 동작·현상** 추출|"성장률이..." → `(성장률)`|
|3순위|상위 □의 주제어를 세분화|□가 "정책 비교"이면 → `(미국)`, `(중국)`, `(한국)`|

#### 키워드 작성 규칙

- **2~6자** 이내의 명사형 (조사·서술어 제외)
- 괄호 `( )` 로 감싸고 한 칸 띄운 후 본문 시작
- 중복 허용 (같은 □ 아래 여러 ○가 같은 키워드를 가질 수 있음)
- 키워드 자체에 명사형 종결 규칙 미적용

#### 예시

```
□ 글로벌 피지컬 AI 시장 규모 및 세그먼트 분석
  ○ (시장규모) 2025년 기준 글로벌 피지컬 AI 시장 규모는 **약 50억 2,120만 달러~52억 3,000만 달러 수준**으로 추산됨.
  ○ (성장률) 연평균 성장률(CAGR) **32.5%~34.6%**로 팽창하여 2033~2035년에는 **497억~836억 달러** 규모 형성이 전망됨.
  ○ (지역별) 북미가 **40.6%**로 시장을 주도하며, 아시아-태평양이 CAGR **34.6%**로 가장 빠른 성장세를 기록 중임.
   ― 하드웨어 부문이 **56.4%~57.4%**의 점유율로 시장을 리드하나, 소프트웨어 부문이 연평균 **34.10%**로 가장 빠른 성장을 보임.
```

---

### 4.6 ○ 핵심맥락 볼드 규칙 ★ 신규

모든 ○ 블록 내에서 **핵심 수치·고유명사·핵심 개념어**를 `**볼드**`로 강조한다.

#### 볼드 적용 대상 (우선순위 순)

|우선순위|대상 유형|예시|
|---|---|---|
|1순위|**수치·통계** (%, 달러, 배, 배율, 기간 등)|`**32.5%**`, `**50억 달러**`, `**3배**`|
|2순위|**핵심 고유명사** (기관·기업·모델명 등)|`**NVIDIA**`, `**딥시크 R1**`|
|3순위|**핵심 개념어** (문단 전체의 결론·판단어)|`**초격차**`, `**TCO 역전**`|

#### 볼드 적용 범위 규칙

- 수치는 **단위 포함** 전체를 볼드: `**약 50억 달러~52억 달러**` (단위 분리 금지)
- 범위값은 **범위 전체**를 볼드: `**32.5%~34.6%**` (~ 포함)
- 고유명사는 **공식 명칭 전체**를 볼드: `**Isaac GR00T N1**`
- 한 문장 내 볼드는 **최대 2~3개** (남발 금지 — 강조 효과 희석 방지)
- ― 블록에는 볼드를 **선택적**으로만 적용 (핵심 수치가 있을 때만)
- □ 블록과 * 출처 블록에는 볼드 **미적용**

#### 볼드 금지 대상

- 조사·어미 (`~은`, `~로`, `~하며` 등)
- 일반 서술어 (`추진함`, `분석됨` 등)
- 키워드 태그 `(시장규모)` 자체

#### 예시 — 볼드 적용 전/후 비교

```
[적용 전]
○ 2025년 기준 글로벌 피지컬 AI 시장 규모는 약 50억 2,120만 달러~52억 3,000만 달러 수준으로 추산됨.

[적용 후]
○ (시장규모) 2025년 기준 글로벌 피지컬 AI 시장 규모는 **약 50억 2,120만 달러~52억 3,000만 달러 수준**으로 추산됨.
```

```
[적용 전]
○ 미국은 에너지부(DOE)의 제네시스 미션을 통해 17개 국립연구소 자산을 AI 훈련 데이터로 전환하고 관련 예산을 3배 이상 증액함.

[적용 후]
○ (미국전략) 미국은 에너지부(DOE)의 **제네시스 미션(Genesis Mission)**을 통해 17개 국립연구소 자산을 AI 훈련 데이터로 전환하고 관련 예산을 **3배 이상** 증액함.
```

## 5. 출처(Source) 처리 규칙

### 5.1 인식 조건

- `출처:` / `자료:` / `참고:` 키워드
- 괄호 내 연도 포함 문장

### 5.2 출력 포맷 (변환 금지)

```
* 출처: 기관명, 「문서 제목」, 발행연도, 관련 링크
```

- 명사형 규칙 **미적용**
- 볼드 규칙 **미적용**
- 위치는 **문단 마지막**

---

## 6. 금지 규칙 (절대 하지 말 것)

❌ 문장 의미를 추가·삭제  
❌ 평가·의견 삽입  
❌ 미사여구 보강  
❌ 요약 생성 (요지는 재배치만 허용)  
❌ 볼드 남발 (한 문장 내 4개 이상 금지)  
❌ □ 블록 및 * 출처 블록에 볼드 적용  
❌ 키워드 태그를 생략하거나 ○ 블록 중간·끝에 배치

> Skill B는 **편집기이지 저자가 아니다.**

## 7. 실패 처리 정책 (Fail-safe)

|상황|처리|
|---|---|
|분해 기준 애매|원문 유지|
|명사형 변환 불가|원문 유지|
|길이 규칙 충돌|가장 상위 규칙 우선|
|구조 판단 실패|단일 ○ 로 출력|
|키워드 추출 불가|`(기타)` 로 대체|
|볼드 대상 불명확|볼드 미적용 (원문 유지)|

---

## 8. 테스트 기준 (QA Checklist)

### 8.1 정량 검증

- 모든 문장 종결이 명사형인가
- 글자 수 범위 초과 문장 없음
- □가 1개 이상인가
- ―가 단독으로 존재하지 않는가
- 모든 ○ 블록에 `(키워드)` 태그가 있는가 ★ 신규
- 한 문장 내 볼드가 3개 이하인가 ★ 신규
- □ 블록과 * 출처 블록에 볼드가 없는가 ★ 신규

### 8.2 정성 검증

- 의미 훼손 없음
- 인용문 원형 유지
- 출처 변형 없음
- 키워드가 문장 내용을 정확히 대표하는가 ★ 신규
- 볼드가 가장 중요한 수치·개념에만 집중되어 있는가 ★ 신규
