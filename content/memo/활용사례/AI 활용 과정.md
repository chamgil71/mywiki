### 0. 개요 (Introduction)

본 문서는 2026년 한 해 동안 개인 프로젝트 및 지식 관리 환경에 인공지능(AI)을 도입하여, 기획부터 개발, 배포, 문서화에 이르는 전 과정을 어떻게 자동화하고 최적화했는지에 대한 실증적 기록입니다.

AI를 단순한 질의응답용 챗봇이 아닌 **'시스템 보조 도구 및 페어 프로그래머'**로 정의하고, 수작업으로 진행되던 파이프라인 병목 현상을 해소하는 데 집중했습니다.

**중점 사용 도구 (Core Toolchain)**

- **지식 기반 및 문서화:** **`Obsidian`** (로컬 기반 제텔카스텐), **`NotebookLM`** (대용량 문서 분석 및 요약)
    
- **프론트엔드 및 배포:** `Lovable` (AI 기반 UI 자동 생성), `Vercel` (Zero-config 자동 배포)
    
- **백엔드 및 데이터:** `Python (FastAPI)`, `Excel`
    
- **버전 관리 및 퍼블리싱:** **`GitHub`**, `Quartz` (마크다운 정적 웹사이트 변환)
    
- **AI 모델링 및 분석:** `Claude`, `Gemini`, `ChatGPT`, `perplexity`

- **디자인 등**: gamma, canva, figma

### 1. AI 협업의 기초: 2026 프롬프트 엔지니어링 가이드

AI에게 전문적인 보고서나 코드를 작성하게 할 때는, 명확한 **페르소나(역할)**와 **형식**을 쥐어주는 것이 핵심입니다.

#### 1.1 프롬프트 필수 포함 5요소

1. **Role (역할):** "너는 글로벌 IT 컨설팅 펌의 수석 AI 산업 애널리스트야." / "시니어 파이썬 개발자야."
    
2. **Context (배경):** "현재 2026년 상반기 AI 트렌드 발표 자료를 기획하고 있어." / "BudgetN의 API 성능을 개선하려고 해."
    
3. **Task (목표):** "최신 뉴스 데이터를 분석해서 핵심 인사이트 3가지를 도출해 줘." / "FastAPI 비동기 처리를 적용해 리팩토링해 줘."
    
4. **Constraint (제약):** "비즈니스 톤앤매너 유지, 구체적 데이터 필수 포함." / "외부 라이브러리 사용 지양, 타입 힌트 포함."
    
5. **Output (형식):** "상단 3줄 요약 후 마크다운 헤딩 및 불릿 포인트로 구조화." / "설명은 주석 처리하고 코드 블록만 출력해."
    

#### 1.2 플랫폼별 프롬프트 적용 방법

- **ChatGPT (OpenAI):** `맞춤 설정`을 통한 글로벌 적용 및 `Explore GPTs`를 활용한 개별 목적용 봇(지시사항 최대 8,000자) 생성.
    
- **Claude (Anthropic):** 전역 설정 대신 `Projects` 단위로 컨텍스트를 분리하고 `Custom Instructions` 및 참고 문서(Knowledge)를 일괄 주입. 사용자 정의 `스킬`로 등록하여 재사용.
    
- **Gemini (Google):** `저장된 정보`에 사용자 컨텍스트를 글로벌로 저장하고, `Gems`를 통해 개별 맞춤형 페르소나 구축.
    
- **Perplexity:** `AI 프로필`에서 전역 규칙(답변 언어, 형식 등)을 세팅하고, 개별 리서치는 `컬렉션`의 AI Prompt 기능 활용.
    
- **Manus (자율형 에이전트):** 별도 세팅 없이 대화창 입력 시 완벽한 '마스터 프롬프트(목표+제약+출력)'를 쏟아붓는 방식으로 태스크 할당.
    

#### 1.3 프롬프트 관리 및 개선

**💡 프롬프트 관리 

- 프로젝트별 프롬프트 템플릿을 엄격히 분리하여 관리.
    
- 공통 프롬프트 구조를 템플릿화하여 재사용성 확보.
    
- 모든 프롬프트를 Obsidian 내 `Prompt Library` 형태로 문서화하여 저장.
    
- 프롬프트 변경 이력을 GitHub에서 버전 관리(History tracking).
    
- 동일 작업 수행 시, 프롬프트 버전별 결과물을 비교 분석하여 지속적 개선.
    

**💡 프롬프트 품질 개선 방법**

- 한 번에 길고 복잡한 요청을 하기보다 **단계별 요청(Step-by-step)** 수행.
    
- 내용을 요구하기 전에 **출력 형식(Output Format)**을 먼저 명확히 정의.
    
- 원하는 결과물의 **예시 입력 및 출력 샘플(Few-shot)** 포함.
    
- 하지 말아야 할 것 등 **제약 조건(Constraints)**을 구체화.
    
- AI의 시각을 고정하기 위해 **역할(Role)**을 전문가 수준으로 구체적 설정.
    

**🔄 프롬프트 재사용 라이프사이클**


> [!tips]
> > Prompt Template 설정 ➔ 프로젝트 맞춤 수정 ➔ 결과 평가 ➔ 프롬프트 로직 개선 ➔ 템플릿 업데이트 및 저장

#### 1.4 실제 실무 적용 프롬프트 예시

- **보고서 생성 특화:**
    
    > "너는 글로벌 IT 컨설팅 펌의 수석 AI 애널리스트야. 현재 2026년 AI 트렌드(Agentic AI 및 AI 인프라 중심)에 대한 발표 자료를 기획 중이야. 아래에 첨부할 Dailynews 수집 데이터를 분석해서, 이번 달 AI 시장의 핵심 인사이트 3가지를 도출하고 상세 보고서 초안을 작성해 줘. 작성 시 객관적이고 전문적인 비즈니스 톤앤매너를 유지하고, 추상적인 전망보다는 구체적인 기업 사례나 기술 명칭을 포함해야 해. 결과물은 가장 상단에 3줄 요약을 배치하고, 본문은 마크다운을 활용해 섹션별 불릿 포인트로 깔끔하게 정리해 줘."
    > 
    > _(Tip: 연구보고서 등을 작성할 때는 도구에서 딥리서치 등을 켜고 진행하는 것을 추천)_
    
- **데이터 분석:** "Pandas를 사용해 주식 시세 CSV 파일에서 월별 수익률을 계산하는 함수를 짜줘. 결과는 데이터프레임 형태여야 해."
    
- **UI 디자인:** "Lovable에서 사용할 예산 입력 폼을 만들어줘. 다크 모드가 지원되어야 하고, 금액 입력 시 천 단위 콤마가 자동으로 찍혀야 해."
    
- **지식 요약:** "이 기술 문서의 핵심 내용을 Obsidian 마크다운 형식으로 정리해줘. 나중에 Quartz로 배포할 거니까 적절한 헤딩(H2, H3)을 섞어줘."

#### 2.1 기본 AI 파운데이션 및 자율형 에이전트 (Core AI & Agents)

모든 프로젝트의 뇌(Brain) 역할을 담당하는 웹 기반 최상위 모델 생태계입니다.

- **Gemini (Google):** 생태계 통합의 핵심. 텍스트 분석 및 구글 워크스페이스 연동에 강력함. (가격: Advanced 구독 월 29,000원)
    
- **Claude (Anthropic):** 코드 논리 설계와 긴 문서 작성 특화. 'Projects'를 통한 컨텍스트 유지 기능이 압도적. (가격: Pro 월 $20)
    
- **ChatGPT (OpenAI):** 다재다능한 스위스 아미 나이프. Custom GPTs 생성 및 데이터 분석용. (가격: Plus 월 $20)
    
- **Grok (xAI):** X(트위터) 실시간 데이터베이스 기반으로 최신 기술 트렌드 수집에 최적화. (가격: X Premium 구독 월 10,400원)
    
- **Manus (자율형 에이전트):** 단순 챗봇이 아닌, 목표를 주면 스스로 리서치하고 파일 구조까지 잡아오는 작업 수행 비서.
    
- **Perplexity / Genspark (AI 검색 엔진):** 환각이 치명적인 리서치 단계에서 출처를 달아주며 병렬 검색 요약 제공. (가격: 기본 무료, Pro 월 $20)
    

#### 2.2 업무 및 기획 (Work & Management)

- **Notion + Notion AI:** 데이터베이스 기반 일정 관리 및 칸반 보드. 회의록이나 기획서 초안의 어투를 즉시 비즈니스 톤으로 교정. (가격: 기본 무료, AI 추가 월 $8~$10)
    
- **Obsidian:** 제텔카스텐 기반의 로컬 마크다운 지식 저장소. 모든 프롬프트와 기획안이 시작되는 베이스캠프. (가격: 개인 무료, Sync 등 부가기능 유료)
    

#### 2.3 학습 및 딥 리서치 (Learning & Deep Research)

- **NotebookLM:** 수십 개의 PDF 논문, 명세서를 업로드해 맞춤형 지식 DB를 구축하고 요약 리포트를 뽑아내는 딥 리서치 특화 툴. (가격: 무료)
    

#### 2.4 이미지 (Image)

- **Nano Banana 2 (Gemini 3 Flash Image):** 구글의 최신 이미지 생성 모델. 고품질 텍스트 투 이미지 및 기존 이미지의 스타일 편집/합성 특화.
    
- **Midjourney / DALL-E 3:** 프로젝트 랜딩 페이지 배경이나 썸네일 등 아티스틱한 디자인 에셋 생성. (가격: Midjourney 기본 월 $10)
    
- **배경 제거 도구 (remove.bg / Photoroom):** UI 버튼, 프로필 등 누끼가 필요한 이미지를 1초 만에 깔끔한 PNG로 분리. (가격: 저해상도 무료, 고해상도 유료)
    

#### 2.5 동영상 (Video)

- **Google Flow (구글 플로우):** 구글의 최첨단 Veo 3.1 모델을 기반으로 한 AI 영상 제작 플랫폼입니다. 프롬프트를 통해 환경음과 립싱크가 포함된 시네마틱 영상을 생성하며, 생성된 클립들을 매끄럽게 연결해 하나의 흐름(스토리)을 만드는 데 특화되어 있습니다. 최근 이미지 생성 기능까지 하나로 통합되었습니다. (가격: 제미나이 프로 구독 시 월 1,000 크레딧 제공. 헤비 유저용은 월 369,000원 요금제 존재)
    
- **Opal (개인 프로젝트):** 유튜브 영상 분석 결과를 프레젠테이션 뼈대로 구조화하는 자체 파이프라인.
    

#### 2.6 음악 및 오디오 (Music & Audio)

- **Lyria 3:** 장르, 감정, 템포를 조절하여 30초 분량의 고품질 BGM을 생성.
    
- **Suno / Udio:** 보컬이 포함된 프로젝트 로고송이나 유튜브 영상용 BGM을 텍스트로 작곡. (가격: 기본 무료 쿼터 제공, Pro 월 $10)
    

#### 2.7 개발 (Development)

단순한 텍스트 에디터를 넘어 AI와 어떻게 결합하느냐에 따라 도구의 위상이 다릅니다.

- **IDE 및 인프라 비교 (VS Code vs. Cursor vs. Antigravity):**
    
    - **VS Code:** 범용적이고 가벼운 전통적 IDE. Copilot 등 플러그인에 의존하며 단일 파일 작업에 적합합니다. (무료)
        
    - **Cursor:** AI 네이티브 IDE. 프로젝트의 전체 폴더를 컨텍스트로 읽어내어 "이 구조에 맞춰 프론트/백엔드 로직 전부 수정해"와 같은 거시적인 페어 프로그래밍이 가능합니다. (가격: 기본 무료, Pro 월 $20)
        
    - **Antigravity:** 코드 에디터라기보다는 AI 애플리케이션 개발을 위한 하드웨어 연동 및 파이프라인 인프라/프레임워크 성격이 강합니다. Cursor 등에서 코드를 짜고 Antigravity 환경에 배포하여 구동하는 방식으로 시너지를 냅니다.
        
    - **Claude Code:** 터미널에서 프로젝트 폴더 전체를 열어놓고 대화하는 에이전틱 CLI 도구. 파일 탐색·수정·실행·git 조작을 직접 수행하며, 대규모 리팩토링이나 여러 파일에 걸친 일괄 수정에 강합니다. 기업 내부망(SSL Inspection) 환경에서도 별도 인증서 설정으로 구동 가능. (가격: Pro 월 $20 구독에 포함)
        
- **Python (FastAPI):** AI가 손대기 힘든 복잡한 핵심 비즈니스 로직 연산과 데이터 파이프라인을 구축하는 백엔드 언어. (무료)
    
- **Lovable:** 프롬프트만으로 실제 동작하는 React 프론트엔드 UI 코드를 자동 생성. (가격: 무료 쿼터 후 월 $20 구독)

#### 4.7 doc-analysis: 내부 기밀문서 로컬 AI 분석 플랫폼

- **실행 과정:** 부처 예산자료·사업계획서 같은 기밀문서(PDF·HWP)를 인터넷 연결 없이 100% 로컬에서 Markdown 변환 → 사업 단위 자동 분할 → 유사도 분석 → 금액 피벗 통합 → 파일 자동 분류까지 처리.
    
- **핵심 기능:** TF-IDF+Jaccard+수치패턴+Sentence-Transformers 임베딩을 결합한 4차원 유사도 군집화, 한글 금액 단위 자동 코어싱+연도별 피벗.

#### 4.16 DailyNews: 서버리스 AI 뉴스 자동 분석 및 발행 파이프라인

- **실행 과정:** 매일 오전 8시 GitHub Actions를 트리거로 영문 및 국문 RSS 피드를 자동 수집합니다. 이 프로젝트의 1차적 목표는 단순한 기사 목록의 취합(Aggregation)이 아니라, **AI 주도적인 뉴스 심층 분석(Analysis)**입니다. 수집된 데이터는 LLM(GPT, Claude, Gemini)을 거쳐 카테고리별 핵심 인사이트가 담긴 Markdown 리포트로 변환되며, 웹사이트(Vercel/GitHub Pages) 배포 및 이메일(Resend API) 발송까지 전 과정이 사람의 개입 없이 100% 자동화됩니다.
    
- **기술 스택:** Python, GitHub Actions (Cron), OpenAI / Gemini API, Resend API, Vercel
    
- **시행착오:** - **비용 최적화:** 토큰 비용과 분석 품질의 균형을 맞추기 위해, 수집된 뉴스 기사 수(20건 기준)에 따라 경량 모델(예: gpt-4o-mini)과 고성능 모델(gpt-4o)을 조건부로 자동 스위칭하는 로직을 구현했습니다.
    
    - **모델 확장성:** 특정 AI 모델에 종속되지 않도록 전략 패턴(Strategy Pattern) 구조를 도입했습니다. 이를 통해 복잡한 코드 수정 없이 환경 변수(`LLM_PROVIDER`)만 변경하여 GPT, Claude, Gemini(2.0 Flash Lite 등 최신 모델 포함)를 자유롭게 교체하며 테스트할 수 있었습니다.
        
- **결과물:** 별도의 서버 유지비 없이 월 1달러 미만으로 구동되는 '완전 자동화된 나만의 AI 뉴스 애널리스트 및 구독 플랫폼'.
    
- **추가 팁:** 시스템 아키텍처 구축 이후에는 철저히 '프롬프트 엔지니어링'에 집중해야 합니다. AI가 수집된 뉴스들을 단순히 요약하는 것을 넘어, 전체 맥락을 짚어내도록 카테고리별 맞춤 프롬프트를 정교하게 다듬는 것이 프로젝트의 핵심 가치입니다.

- **실행 과정:** 100종목(확장 가능)의 확정 일봉·배당 데이터를 축적하고, 정규화한 기간수익률·배당률로 비교하며, 세운 투자 원칙을 알람 → 모의거래(Dry-Run) → 실거래 순서로 신중하게 단계 실행하는 통합 플랫폼 구축.
    
- **현재 상태:** 0단계(검증)~5단계(리스크 게이트+Dry-Run)까지 코드·문서 작업 완료. 6단계(실거래)는 착수 전 — 장기 Dry-Run 운영과 최종 승인이 전제조건.
    
- **기술 스택:** Python(백엔드), KIS Open API, mypy strict 게이트.
    
- **결과물:** 조회·분석은 Standard, 자동매매는 Enterprise 안전도로 나눠 다루는 자산관리 통합 플랫폼(진행 중).

- **결과 및 인사이트:** 완벽한 변환은 어려웠으나, 글자와 그림을 분리하여 JSON으로 구조화하는 비전(Vision) AI 프롬프팅의 가능성을 확인. 노트북LM의 출력물은 구글 슬라이드 등을 거치면 일부 편집 가능하다는 우회로 발견.

### 6. 응용 시나리오 
#### 시나리오 1: 앱 기획부터 배포까지

_머릿속에 있는 아이디어(예: 개인 예산 관리 대시보드)를 실제 인터넷 주소가 있는 웹사이트로 만드는 과정입니다._

1. **기획 및 리서치 (`Perplexity` ➔ `Notion`)**
    
    - **Perplexity**에 접속해 "요즘 유행하는 가계부 앱의 핵심 기능 3가지는?"이라고 물어보며 트렌드를 조사합니다.
        
    - 조사한 내용을 바탕으로 **Notion**에 간단한 메뉴 구성과 필요한 기능들을 글로 정리합니다.
        
2. **화면 디자인 및 뼈대 만들기 (`Canva` ➔ `Lovable`)**
    
    - **Canva**에서 서비스에 어울리는 예쁜 로고를 5분 만에 하나 만듭니다.
        
    - **Lovable** 채팅창에 노션에 적어둔 기획안을 붙여넣으며 "왼쪽엔 메뉴가 있고, 가운데는 지출 내역을 입력하는 다크모드 화면을 짜줘"라고 명령해 실제 눈에 보이는 프론트엔드 화면(React)을 뽑아냅니다.
        
3. **핵심 기능 연결 (`Cursor` + `Python` ➔ `Supabase`)**
    
    - **Cursor** 에디터를 열고 Lovable이 만들어준 코드를 가져옵니다. AI에게 "이 화면에서 '저장' 버튼을 누르면 데이터가 저장되게 파이썬 코드를 짜줘"라고 시킵니다.
        
    - 저장소 역할을 할 데이터베이스는 **Supabase**를 연동하여 복잡한 서버 구축 없이 로그인과 데이터 저장 기능을 해결합니다.
        
4. **배포** (`GitHub` ➔ `Vercel`)**
    
    - 완성된 코드를 **GitHub**에 저장(Push)합니다.
        
    - **Vercel**에 접속해 내 깃허브를 연결하기만 하면, 복잡한 서버 세팅 없이 `https://나의앱.vercel.app` 이라는 인터넷 주소가 생성되어 누구나 접속할 수 있게 됩니다.

### 시나리오 2: 나만의 AI 뉴스레터 자동화 (정보 수집 파이프라인)

_매일 내가 관심 있는 분야의 뉴스를 수집해 AI가 요약하고 내 이메일로 보내주는 자동화 비서를 만듭니다._

1. **기초 코드 작성 (`ChatGPT` / `Claude`)**
    
    - **ChatGPT**나 **Claude**에게 "파이썬으로 매일 아침 IT 뉴스 기사 제목과 링크를 수집하는 코드를 짜줘"라고 명령해 기본 뼈대 코드를 받습니다.
        
2. **AI 분석 뇌 장착 (`AI Studio` ➔ `Cursor`)**
    
    - **AI Studio**에 들어가 구글 Gemini의 API 키(비밀번호)를 무료로 발급받습니다.
        
    - **Cursor**를 열고 수집 코드 뒤에 Gemini API를 붙여넣은 뒤, "수집한 뉴스를 3줄로 요약하는 로직을 추가해 줘"라고 AI와 대화하며 코드를 완성합니다.
        
3. **발송 및 무인 자동화 (`Resend` ➔ `GitHub Actions` 또는 `Anti Gravity`)**
    
    - **Resend**에 가입해 파이썬 코드로 이메일을 보낼 수 있는 세팅을 마칩니다.
        
    - 이 파이썬 코드를 24시간 내내 켜둘 필요 없이, **GitHub Actions**(또는 개인 서버인 **Anti Gravity** 환경)에 올려 "매일 아침 8시에 이 코드를 자동으로 실행해라"라고 예약해 둡니다.

### 시나리오 3: 방대한 자료를 실무용 보고서로

_수십 장의 논문이나 기술 문서를 읽고, 세련된 비즈니스 보고서나 PPT로 탈바꿈시킵니다._

1. **딥 리서치 및 지식 압축 (`NotebookLM`)**
    
    - 영문으로 된 두꺼운 PDF 문서나 복잡한 규정집 여러 개를 통째로 **NotebookLM**에 업로드합니다.
        
    - "이 문서들을 종합해서 2026년 AI 시장 전망을 5가지 포인트로 요약해 줘"라고 질문하여 엑기스만 뽑아냅니다.
        
2. **초안 정제 및 구조화 (`Claude` / `Obsidian`)**
    
    - 뽑아낸 요약본을 **Claude**에게 가져가 "너는 수석 컨설턴트야. 이 내용을 공식적인 비즈니스 보고서 톤(명사형 종결어미 등)으로 다듬고 목차를 짜줘"라고 시켜 완벽한 텍스트 초안을 만듭니다.
        
    - 완성된 초안은 **Obsidian**에 저장해 두고 나만의 지식 자산으로 보관합니다.
        
3. **최종 시각화 및 문서 렌더링 (`Gamma` 또는 `Python` 모듈)**
    
    - 당장 발표가 필요하다면 정제된 텍스트를 **Gamma**에 던져넣어 1분 만에 고품질 PPT 슬라이드로 구워냅니다.
        
    - 만약 회사 양식(HWPX 등)에 맞춰야 한다면, **Python** 코드(문서 변환 모듈)를 이용해 내용 한 글자 틀리지 않고 정해진 한글 문서 빈칸에 자동으로 텍스트를 꽂아 넣습니다.

### 시나리오 4: 퍼블릭 위키 구축

_혼자만 보던 메모를 체계적인 웹사이트 블로그로 만들어 대중과 공유합니다._

1. **로컬 지식 축적 (`Obsidian`)**
    
    - 인터넷이 끊겨도 작동하는 **Obsidian**을 열어 오늘 공부한 파이썬 문법이나 AI 프롬프트 팁을 마크다운 형식으로 작성합니다. 단어에 `[[ ]]` 링크를 걸어 문서들을 유기적으로 연결합니다.
        
2. **웹사이트 형태로 번역 (`Quartz`)**
    
    - 옵시디언에 쌓인 투박한 텍스트 메모들을 모바일에서도 보기 좋게 만들어주기 위해 **Quartz** 엔진을 세팅합니다. 쿼츠가 내 메모 폴더를 읽어 예쁜 웹페이지(HTML) 코드로 싹 변환해 줍니다.
        
3. **영구적인 퍼블리싱 (`GitHub` ➔ `Vercel`)**
    
    - 변환된 코드를 **GitHub**에 저장하면, 연결해 둔 **Vercel**이 이를 감지하고 자동으로 내 개인 지식 블로그 웹사이트를 갱신합니다.
        
    - 이제 로컬에서 옵시디언 메모를 수정하고 깃허브에 올리기만 하면, 알아서 전 세계 누구나 볼 수 있는 '나만의 디지털 가든'이 업데이트됩니다.
        


#### 확장 시나리오 1: 사내 규정 / 나만의 지식 기반 AI 챗봇 서비스

_기존에 옵시디언이나 위키로 문서를 '보여주기만' 했다면, 이제는 그 문서를 바탕으로 사용자와 '대화하는' 똑똑한 챗봇을 만듭니다._

1. **지식 데이터베이스 구축 (`Notion` ➔ `Supabase`)**
    
    - **Notion**에 회사 규정집이나 특정 주제의 Q&A 정리본을 텍스트로 쭉 작성합니다.
        
    - 이 텍스트 데이터를 **Supabase**의 데이터베이스에 업로드합니다. (이때 AI가 이해할 수 있는 형태인 '벡터 DB'로 변환하는 과정을 거칩니다.)
        
2. **AI 채팅 두뇌 연결 (`Python` + `OpenAI API / Gemini API`)**
    
    - **Python**으로 간단한 백엔드 서버를 짭니다. 사용자가 질문을 던지면, 파이썬 코드가 Supabase에서 관련 규정을 먼저 검색한 뒤, 그 내용을 **ChatGPT**나 **Gemini** 모델에 던져주어 "이 규정을 바탕으로 친절하게 대답해 줘"라고 지시합니다.
        
3. **사용자용 채팅 화면 개발 (`Lovable` ➔ `Vercel` + `Cloudflare`)**
    
    - **Lovable**에 "카카오톡처럼 왼쪽에 사용자, 오른쪽에 AI가 대화하는 말풍선 UI를 만들어줘"라고 지시하여 프론트엔드 코드를 뽑아냅니다.
        
    - 완성된 프론트엔드와 파이썬 서버를 연동한 뒤 **Vercel**에 배포합니다. 외부의 무분별한 공격이나 트래픽 과부하를 막기 위해 **Cloudflare** 방화벽을 씌워 안전한 나만의 챗봇 서비스를 완성합니다.
        

#### 확장 시나리오 2: 완전 자율형 자동 생산 공장

_사람이 프롬프트를 일일이 치며 대화하는 단계를 넘어, 목표만 주면 AI가 알아서 폴더를 뒤지고 리서치하여 최종 산출물까지 만들어내는 에이전틱(Agentic) 워크플로우입니다._

1. **자율 리서치 및 데이터 수집 (`Manus` + `Perplexity`)**
    
    - 자율형 에이전트인 **Manus**에게 "국내 AI 에듀테크 스타트업 상위 5개사의 최근 3년 매출과 주요 서비스를 조사해서 엑셀 파일로 바탕화면에 저장해"라고 한 줄 명령만 내립니다.
        
    - Manus가 가져온 데이터 중 팩트 체크가 필요한 부분은 **Perplexity**에 검색하여 출처(링크)가 명확한 교차 검증을 진행합니다.
        
2. **제안서 초안 작성 및 디자인 (`Claude` ➔ `Gamma`)**
    
    - 수집된 엑셀과 검증된 자료를 한 번에 묶어 **Claude**의 'Projects'에 던져넣고 "이 자료들을 바탕으로 우리가 진입할 틈새시장을 공략하는 신규 사업 제안서 초안을 작성해"라고 지시합니다.
        
    - Claude가 논리적으로 뽑아낸 텍스트 뼈대를 그대로 복사해 **Gamma**에 붙여넣고 엔터를 치면, 어울리는 이미지와 도표가 포함된 화려한 PPT 슬라이드가 단 1분 만에 생성됩니다.
        

#### 확장 시나리오 3: 낡은 레거시 코드베이스의 대규모 AI 리팩토링

_단일 스크립트 작성이나 툴 조합을 넘어, 수십 개의 파일이 얽힌 거대한 폴더(프로젝트) 단위의 구조를 AI로 한 번에 개선하는 개발자/엔지니어 특화 시나리오입니다._

1. **프로젝트 환경 세팅 및 분석 (`GitHub` ➔ `VS Code`)**
    
    - **GitHub**에 방치되어 있던 수년 전의 낡은 파이썬 프로젝트 코드를 로컬 컴퓨터로 내려받습니다(Clone). **VS Code**로 폴더를 열어 전체적인 파일 구조를 파악합니다.
        
2. **터미널 기반 대규모 수정 (`Claude Code`)**
    
    - 파일을 하나씩 여는 대신, 명령창(터미널)에서 **Claude Code**를 실행합니다. "이 프로젝트의 모든 파일에 쓰인 구형 라이브러리 문법을 최신 문법으로 일괄 업데이트하고, 오류가 나면 알아서 수정해 줘"라고 명령합니다. AI가 직접 폴더를 돌아다니며 수십 개의 파일을 동시에 수정하고 테스트합니다.
        
3. **세밀한 로직 튜닝 및 하드웨어 배포 (`Cursor` ➔ `Anti Gravity`)**
    
    - 대규모 수정이 끝난 코드를 **Cursor** 에디터로 엽니다. 특정 핵심 기능에서 미세한 논리적 결함이 있다면 에디터 안에서 AI와 페어 프로그래밍을 하며 튜닝합니다.
        
    - 완벽하게 동작하는 최신화된 코드를 **Anti Gravity** 프레임워크 환경에 배포하여, 내 방에 있는 미니 PC 홈 서버 위에서 안전하게 24시간 구동되도록 만듭니다.

### 7. 공통 적용 (Development Principles)

수많은 툴과 파이프라인을 관통하는 2026년 프로젝트의 대원칙입니다.

1. **문서 중심 개발 방식 적용:** 코드를 짜기 전에 Obsidian 등에서 문서화를 먼저 진행
    
2. **AI 생성 ➔ 검증 ➔ 수정 프로세스:** AI의 산출물을 초안으로 활용한 뒤 검증
    
3. **극단적 자동화 지향:** 자동화 가능한 부분은 모두 자동화
    
4. **툴 간 연계 중심 설계:** 단일 도구에 의존하지 않고 각 툴의 장점을 연계
    
5. **반복 작업 최소화:** 불필요한 반복을 제거하여 효율을 극대화

6. **4-Layer 디렉토리 분리 아키텍처:** 모든 프로젝트는 `backend`(로직), `frontend`(UI), `storage`(데이터), `docs`(설계)의 4계층으로 엄격히 분리하여 유지보수성 확보.
   
7. **안전한 전역 경로 관리:** 로컬 환경에 종속되지 않도록 `Pathlib`을 활용하여 경로를 동적으로 계산하고, 민감한 원본 데이터는 `.gitignore`로 엄격히 통제.

### 8. 결과 및 인사이트 (Conclusion)

#### 8.1 수치적, 체감적 변화

- **생산성 변화:** 문서 작성 시간 감소, UI 설계 시간 단축, 자동 배포 환경 구축, 데이터 생성 자동화 완료.
    
- **개발 방식의 변화 (Paradigm Shift):**
    

| **구분**      | **AI 도입 전 (Before)** | **AI 도입 후 (After)** |
| ----------- | -------------------- | ------------------- |
| **개발 프로세스** | 수동 UI 구현             | 프롬프트 기반 생성          |
| **배포 및 관리** | 수동 배포                | 자동 배포               |
| **지식 자산화**  | 문서 따로 관리             | 문서 중심 개발            |
| **데이터 처리**  | 데이터 수작업              | 데이터 자동 생성           |

#### 8.2 레슨런 (Lessons Learned)

- **문서 중심 개발 방식** : 실제 코딩은 AI가 하나 문서 설계를 제대로 하면 코딩오류를 막을 수 있음
	- 데이터 정합성 및 구조화를 먼저 진행하고 체계적인 접근 
    
- **자동화 가능한 부분은 모두 자동화**하여 불필요한 리소스 낭비 제거
    
- **AI는 완벽한 주체가 아닌 '보조 도구'**로서 활용할 때 가장 큰 시너지
    

#### 8.3 마무리

결론적으로 2026년 프로젝트 경험을 관통하는 한 문장

> **백문이 불여일견(百聞不如一見) 이고, 백견이 불여일타(百見不如一打) 이며,** 
> **백타가 불여일문(百打不如一問) !!**

- **어떻게 질문할 것인가?** 결국 핵심은 프롬프트의 질에 달려 있습니다.
    
- **구조를 알아야 하고 내가 하려는 게 무엇인지 정확하게 파악하는 게 중요**
 
- 본질을 명확히 정의할 때 AI가 최고의 결과물로 답을 줍니다.
